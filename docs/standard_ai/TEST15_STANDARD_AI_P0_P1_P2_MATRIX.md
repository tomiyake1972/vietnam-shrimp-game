# Test15前 標準経営AI（#05） P0/P1/P2優先度判定

作成: Cowork #05（AI設定）／2026-08-05
判定基準（三宅さんご指示§17）: 「最適か」ではなく「固定化・誤作動がAIの自己破壊、または人間プレイヤーによる市場の無競争制覇を招くか」で判定する。

## 1. P0（Test15開始前に必須）

### P0-1: 商品別労務係数の欠如（Test15の新機能とAIの不整合リスク）

現行#05は`computeRequiredRegularHeadcount`で単一労務効率係数（HOSO/PD/VAP区別なし）しか使わない（TEST15_STANDARD_AI_CURRENT_CAPABILITY_AUDIT.md §5参照）。Test15では商品別労務負荷（PD/VAPの労務負荷がHOSOの1.8倍・3.0倍相当）が**ゲーム環境側の新機能として稼働する**。AI側がこれを認識しないまま高PD/VAP比率の生産計画を立てると、歴史的クレース（`feature/v2-product-labor-intensity`ブランチで実際に観測された、5社が32ターンの大半でデフォルトを繰り返した事例）と同じ自己破壊パターン（ワーカー不足→残業/臨時費急増→現金逼迫→原料調達制約→生産減→デフォルト連鎖）が再発するリスクがある。

**判定根拠**: これは「最適でない」ではなく「Test15の新ゲーム機能が有効化された瞬間にAIが構造的に自滅しうる」という、まさにP0の定義に該当する事象である。ただし三宅さんご指示により、労務エンジン自体・パラメータは変更禁止（§23-24）のため、**今回はこの実装を行わない**。Test15開始前に必要な最小対応は「Standard AIの生産・労務判断が商品別労務係数を認識してPD/VAP比率を過度に引き上げないよう、最低限のセーフガードを入れるか、Test15初回はPD/VAP機能を段階的に有効化する」という運用判断を三宅さんに委ねる（詳細はTEST15_STANDARD_AI_INTEGRATION_RECOMMENDATION.mdの結論参照）。

### P0-2〜: 該当なし（他ドメインはP0基準を満たさない）

以下の候補は検討したが、いずれもP0の基準（自己破壊・市場無競争化）を満たさないと判断した。

- **営業人員（採用/減員）**: 8Q/16Qの本番経路実測で線形増加・据え置き（liquidity gate）のいずれも経済的に正当であり、複利的暴走（18→27→41→62…のような指数関数的増加）は既に別セッションで解消済みであることを確認した。SAI-3Aハーネスの「80固定」問題はツールのアーティファクトであり、本番挙動ではないため、これ自体はP0ではない（§2参照）。
- **Worker増減**: 6,300→2,300台へ収束し安定。ゼロクラッシュなし。
- **資金・デフォルト**: 16Q実測でdefault/underwriting-freezeともに0件。
- **工場capex・PD機械化・VAP開発の未実装**: これらが「存在しない」こと自体はAIを積極的に破壊するわけではない（Standard AIが単に投資しないだけであり、市場を壊す方向には作用しない）。P1〜P2として扱う。

## 2. P1（Test15中は観察対象、プレイ自体は可能）

- **サプライヤーシェア上限（35%）への非認識**: AI自身は上限を意識せず、ダウンストリームの`sales/allocation.ts`が機械的に enforced する構造。AIが無自覚に上限へ張り付く可能性があるが、ゲームルール自体は正しく機能するため致命的ではない。
- **営業人員増員のガバナー上限依存**: Target Scale帯への到達が8Q/16Qいずれのウィンドウでも未達（既知の課題、`STANDARD_AI_8Q_SIMULATION_TARGET_SCALE_2026-08-05.md`参照）。線形増加自体は正常だが、チューニング余地あり。
- **FG在庫の高水準滞留**: 4,800t前後で頭打ちになるが売り切れない傾向。市場崩壊には至らないが非効率。
- **Worker増員側（`HIRING_FOR_SUSTAINED_SHORTAGE`）が今回の計測期間で一度も発火しなかった**: 現状のfixture初期条件（6,300人）では検証されていない。市場を壊すリスクは低いが、Test15中に別シナリオで発火するか要観察。
- **factory capex / PD機械化 / VAP開発の未実装（機能追加の観点）**: AIが投資判断を全く行わないため、人間プレイヤーがこれらの投資で長期的に圧倒的優位に立つ可能性がある。ただしTest15の主目的が「人間側のこれら新機能の手動検証」であることを踏まえると、AIが追随しないこと自体は許容範囲内（市場を壊す方向ではなく、AI側が単に停滞するだけ）。
- **均質5社構成でのcash同時到達**（BAL/MASS/CONSVの完全同一挙動）: heterogeneity flagを有効化した追加計測が望ましいが、Test15自体の実行を妨げるものではない。

## 3. P2（Test15後の改善対象）

- Strategic Intent / Target Scale帯のさらなる精緻化（会社別性格の反映等）。
- Target Scale到達を早める方向でのcapacity飽和曲線・ガバナー再設計（ゲームパラメータ変更を伴うため慎重な検討要）。
- 4期先能力計画テーブルの精緻化。
- 長期市場シナリオ予測。
- サプライヤーシェアのソフト制約化。
- 会社アーキタイプ（性格）の本格導入。
- AI Management Meeting機能。
- 高度な資本配分ロジック（`diagnosis/financialCapacity.ts`・`diagnosis/marketOpportunity.ts`・`diagnosis/shadowSalesAllocation.ts`・`diagnosis/businessScaleProfile.ts`の実接続化を含む）。
- Market Evolution Investment・PD機械化・VAP開発・工場新設の本格実装（ポーティング先はTEST15_STANDARD_AI_INTEGRATION_RECOMMENDATION.md参照）。

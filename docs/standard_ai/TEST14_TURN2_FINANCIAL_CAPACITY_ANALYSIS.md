## 4. AR/APタイミングの確認

本再現ケースでは`receivablesNotYetDueUsd=0`（全額が当期決済）だったため、「ARの一部を過大に計上していないか」の直接的な差分確認はできなかった。ただし、単体テスト（`financialCapacity.test.ts`）では、`receivablesNotYetDueUsd>0`の場合に`projectedCashBeforeFinancingUsd`が売掛金全額加算より必ず小さくなることを構造的に確認済みであり、輸入原料についても「当期新規発注1,000t×$3.0/kgの代金（$3,000,000）」が当期のキャッシュアウトには一切含まれないこと（次期決済のため）を確認済みである。

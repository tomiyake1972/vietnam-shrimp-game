# 経営判断レビュー事項（Claude Code が自分で決めなかったもの）

Training Harness Batch 001 で検出したが、**経営哲学・ゲーム設計の判断に属するため Claude Code の判断では変更しなかった**事項。判断を仰ぐ。

---

## MJ-001 市場集中の是非（営業人員の50%を最高単価市場へ投じる規則）

**事実**: `decision/sales.ts` は営業人員配分の基礎となる市場別販売目標を「前期参照価格が最高の市場に 50%、残り4市場に 12.5% ずつ」で配る。市場規模は考慮されない。結果として、単価が高く規模が小さい日本市場へ総営業力の半分が投じられる状態が、5社すべて・ほぼ全期間（1,600 company-quarter 中 1,550件）で継続している。

**判断が必要な理由**: 「単価の高い市場に集中する」こと自体は正当な戦略でありうる。誤りと断定できるのは「規模を一切見ていない」という点までであり、**どの程度集中すべきかは経営方針**である。

**Claude Code の推奨**: 集中度をパラメータとして外に出し、値の決定は人が行う。配分の基礎には自社実績から推定した市場別の吸収実績を加える（詳細と選択肢は `TEST15_JP19_ROOT_CAUSE.md`）。

**未実施の理由**: 上記のとおり方針決定が必要なため。また根本解（市場別需要量を観測へ配線する）は**ゲーム環境の変更に当たり、今回の指示で明示的に禁止されている**。

## MJ-002 5社の経営性格差が営業配分に現れていないこと

**事実**: 市場集中は BAL / MASS / JPQ / VAP / CONSV の5社すべてで同じ形で起きている。`orientationProfile.ts` の市場志向倍率（0.80〜1.25）は存在するが、基礎重みの 50% / 12.5% を覆すほどの効きはない。

**判断が必要な理由**: 「5社が同じ市場戦略を取る」ことを許容するのか、経営性格の差として分かれるべきかは、ゲームとしての設計判断である。

---

## MJ-003 MASS の継続赤字をどう扱うか

**事実**: C03 適用後も MASS は32四半期累計で -170M の営業赤字。turn 13 以降の完全凍結（生産0のまま20四半期同じ判断を繰り返す）は解消したが、収益性は回復していない。設備稼働率は 0.06 のまま。

**判断が必要な理由**: MASS の fixture（大規模設備・大量常用ワーカー）が現行シナリオで採算に乗るのか、そもそも「苦戦する会社」として設計されているのかで、AI側でどこまで救うべきかが変わる。AI に「早期に大幅縮小する」判断をさせるべきかどうかは経営哲学に属する。

**Claude Code の見解**: MASS の固定費構造に対して、AI が人員・設備規模を早期に縮小する判断を持たないことが赤字の主因と見ている。ただし「大規模設備を持つ会社が早々に縮小するのが正しいのか」は判断を仰ぐべき事項。

## MJ-004 設備投資提案が全版で0件

**事実**: baseline / C03 いずれも 32四半期 × 5社 × 10 seed で capex 提案が **1件も発火していない**。

**判断が必要な理由**: 現行シナリオでは設備能力が binding にならないため発火しないのか、capex 判断の入口条件が厳しすぎるのかを切り分ける必要がある。前者ならゲーム設計上の想定どおり、後者なら AI 側の欠陥。平均設備稼働率が 0.42 であることは前者を示唆するが、確定していない。

**未実施の理由**: 切り分け前に閾値を触ると、Cycle 1 の C02（もっともらしいが実測で棄却された仮説）と同じ誤りになる。

# Batch 002 で追加された判断事項

## MJ-005 観測需要の内生性と、市場の自己強化的な縮小

**事実**: `targetDemand` の市場別ウェイトは `market/consumerInventory.ts` の `deriveMarketWeightsFromDesiredPurchase` により消費地の希望購買量から決まり、それは5社が実際にその市場へ供給した量の影響を受ける。したがって **observed market demand は完全に外生ではない**。

実測（seed `sai-train-standard-001`, 32四半期）:

| 市場 | turn1 | turn32（C03・JP集中時代） | turn32（Batch 002） |
|---|---|---|---|
| CN | 67,553 | 176,992 | 191,721 |
| US | 41,463 | 58,619 | 65,515 |
| EU | 32,750 | 7,225 | **1,029** |
| JP | 13,072 | 3,951 | **161** |
| OTHER | 20,050 | 15,539 | 3,900 |

EU・JP の縮小は**両方の版で起きている**（主因は既存の市場進化ダイナミクス）が、Batch 002 の観測需要ベース配分がそれを加速している。AIが小さい市場から合理的に撤退すると、その市場はさらに縮小し、撤退が自己強化される。

**判断が必要な理由**: これがゲームデザインとして意図された挙動（放置すれば市場が消える）なのか、市場が完全には消えないよう下限を持つべきなのかは、ゲーム設計の判断である。`ENVIRONMENT_ISSUE_CANDIDATE` としても報告する。Claude Code はメカニクスに触れていない。

## MJ-006 設備投資の入口条件（capex sustained ゲート）

**事実**: capex は 1,600 company-quarter で 0 件。funnel 監査の結果、**財務ゲートは1件も落としておらず、100%（219/219）が `sustained` ゲートで落ちている**。このゲートは会社全体の設備稼働率 ≥ 0.92 を要求するが、実測の最大値は 0.877 であり構造的に到達不可能。

根本原因は「商品別ラインの増設判断に、会社全体の集計稼働率を使っている」という比較対象の不一致。

**判断が必要な理由**: §I により factory investment threshold は判断を仰ぐ対象。また「そもそもこのシナリオで設備投資は不要」という設計意図なのかどうかも確認が必要。閾値を下げる修正は行っていない。

## MJ-007 MASS の構造的過大設備をどう扱うか

**事実**: MASS の HOSO 能力 30,000t/Q・共通前処理 36,000t/Q は、国内原料市場が1社へ供給し得る量を構造的に超えている（設備稼働 0.06、原料不足は他社の2桁増）。

**判断が必要な理由**: MASS が「合理的に経営しても苦戦する会社」として設計されているのか、AIが早期に大幅縮小すべきなのかで、対応が正反対になる。§I により long-term Target Scale・縮小の速さは判断を仰ぐ対象。

## MJ-008 営業がボトルネックでなくなった後の採用方針

**事実**: A14（営業の限界価値が負）が 63 → 754 件。文面は「販売希望量に対し成約100%。営業は制約になっていない」。それでも累計採用は 3,447 → 3,982 人と増えている。

**判断が必要な理由**: 「需要が充足していても営業体制を厚くしておく」ことに戦略的価値を認めるかは経営判断。営業人数への hard cap は置いていない。

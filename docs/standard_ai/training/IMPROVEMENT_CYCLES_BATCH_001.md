## Cycle 1 — C02: 国内買付の提示価格を需給・自社不足に応じて引き上げる → **REVERT**

### 仮説

`decision/procurement.ts` が `priceAdjustment` を常に 0（前期参照価格ちょうど）で提示しており、国内買付の配分が提示価格順の water-fill である以上、需要超過局面で恒常的に配分負けしているのではないか。原料不足 6,792,568t の主因ではないか。

### 実装

前期の公開清算結果（`vietnamDomesticPriorMarket` の supply / effectiveDemand）から需給逼迫度を、自社の在庫ポジションから不足率を求め、両者の線形結合で上乗せ比率を決める。上限は「加工して売ったときに最低貢献利益が残る買値」から導いた採算上限で頭打ちにする。特定の会社・市場・四半期を名指しした固定値は置いていない。

### 結果（standard profile, 1,600 company-quarter）

| 指標 | before | after | 判定 |
|---|---|---|---|
| 営業利益 | -180,928,719 | **-507,601,898** | 大幅悪化 |
| 原料不足 | 6,792,568 t | 6,801,300 t 相当 | **改善せず** |
| 成約量 | 11,039,964 t | 10,909,687 t | わずかに減 |

会社別に見ると、BAL の原料不足は 3,077 → 3,077t、JPQ 1,917 → 1,917t、VAP 1,460 → 1,460t、CONSV 1,187 → 1,187t と**1トンも動かなかった**。MASS は 671,616 → 675,380t とむしろ微増。上乗せは 279〜300 / 320 四半期で実際に発火していたので、実装が動いていなかったわけではない。

### 判定と学び

**仮説を棄却し revert した。** 現行シナリオでは、国内買付の配分は提示価格で決まっていない（供給量・シェア上限など別の要因が binding）。原料単価だけが上がり、全社の利益が悪化した。

`priceAdjustment` がリテラル 0 で固定されているのはコードとしては依然不自然（`ratioAdjustmentToUsd` は ±0.3 のクランプ付きで「使われる前提」に見える）だが、**現時点では触るべきでない**。F-002 の優先度を下げた。

## Cycle 2 — C03: 生産計画を原料調達可能性で上限する → **KEEP**

### 仮説

MASS は原料在庫 0・現金 0 の状態で 29,070t の生産計画を 20四半期立て続けている。`decision/production.ts` に原料入手可能性への参照が一行も無いため、実行不能な計画が労働・調達・販売の全下流判断を汚染しているのではないか。

### 実装

`decision/production.ts` に原料調達可能性の上限を追加した。

```
上限 = 手元で使える原料 ＋ 当期到着が確定している輸入 ＋ 当期の正味流動資源で買い増せる量
```

- 「正味流動資源」＝ 現金 ＋ 当期決済予定の売掛金 − 当期決済予定の買掛金
- 上限を超える場合のみ、商品構成を変えずに比例配分で縮小する（どの商品を削るかという経営判断はしない）
- 縮小した場合は理由コード `PRODUCTION_LIMITED_BY_RAW_MATERIAL_FEASIBILITY` を必ず出す（沈黙して縮めない）
- 参考価格が観測できない turn1 では適用しない（観測に無い値で判断しない）
- 市場の供給量・自社への配分量は仮定していない（観測に存在しないため）。したがってこれは**上限側の見積り**であり、資金的に無理のない計画を不必要に縮めることはない

使ったのは既存の観測値のみ（`rawMaterialAvailable` / `rawMaterialCertainInboundThisPeriod` / `cashUsd` / `receivablesDueThisPeriodUsd` / `payablesDueThisPeriodUsd` / `vietnamDomesticPriorPrice`）。新しい情報源・ゲームルールは追加していない。

### 途中で見つかった不具合と修正

最初の実装では上限を**現金残高だけ**で計算していた。この版は既存テスト7件を落とした:

```
E社(JPQ)の養殖池入れ計画が turn 3→4 で80.6%変化しており、振り子的挙動の疑いがある
（許容: 60%以下、系列: 6650.0, 4988.6, 3226.7, 5826.6, 3629.6, 2406.9, 6559.9, 3507.3）
```

現金残高は入出金のタイミングだけで四半期ごとに大きく振れるため、健全な会社の計画上限までが振り子状に揺れていた。売掛金の当期入金・買掛金の当期支出を織り込んだ正味流動資源に変更したところ、振動は解消し、既存テスト2,425件がすべて通った。

### 結果（standard profile, 1,600 company-quarter）

| 指標 | before | after | 変化 |
|---|---|---|---|
| **営業利益** | -180,928,719 | **+460,106,219** | **+641,034,938** |
| 当期純利益 | -1,464,985,413 | -730,808,453 | +734,176,960 |
| **原料不足** | 6,792,568 t | **351,046 t** | **-94.8%** |
| 遊休労務費 | 971,418,195 | 534,300,317 | -45.0% |
| 成約量 | 11,039,964 t | 11,044,083 t | +0.04% |
| 債務超過四半期 | 164 | 133 | -31 |
| 平均労働稼働率 | 0.851 | 0.879 | +0.028 |
| 最低現金 | -99,951,400 | -47,237,027 | 改善 |
| 支払不能 | 0 | 0 | 変化なし |

会社別（1 seed 平均・32四半期累計）:

| 会社 | 営業利益 before → after | 原料不足 before → after |
|---|---|---|
| BAL | 80,304,111 → **81,522,214** | 3,077 → 3,077 |
| MASS | -230,223,143 → **-170,258,024** | **671,616 → 27,463** |
| JPQ | 59,679,043 → **60,658,966** | 1,917 → 1,917 |
| VAP | 4,264,725 → **5,229,381** | 1,460 → 1,460 |
| CONSV | 67,882,393 → **68,858,085** | 1,187 → 1,187 |

**5社すべてで営業利益が改善し、悪化した会社は無い。** 成約量はほぼ横ばい（+0.04%）なので、「売るのをやめて利益を出した」のではなく、「作れない量を作ろうとするのをやめた」ことによる改善である。

監査 findings では A06（原料不足下の生産計画）が 280 → 98 件へ減少した。A08（労働不足への無手当）は 274 → 343 件へ増えているが、これは生産計画が現実的になった結果として労働制約が可視化されたためと見ており、悪化とは判断していない（Batch 002 で検証する）。

### 判定

**KEEP。** 5社すべてで改善、既存テスト2,425件すべて通過、`environmentFingerprint` 不変。

MASS は依然として赤字（-170M）であり、完全には救えていない。これは正直に記録する。turn 13 以降の完全凍結は解消したが、収益性そのものの改善は Batch 002 以降の課題。

## Cycle 3-5 を実行しなかった理由

残る主要 finding は次の3つで、いずれも Claude Code の単独判断で進めるべきでないと判断した。

- **F-003 / JP19（A01, 1,550件）** — 修正には市場規模の観測をどう扱うかの判断が要る。選択肢2（観測へ配線）はゲーム環境の変更に当たり、今回の指示で明示的に禁止されている。選択肢1（自社実績からの学習）を推奨するが、集中度は経営哲学に属するため判断を仰ぐ（`TEST15_JP19_ROOT_CAUSE.md`）。
- **F-006（B_STRATEGIC_MARKET_CONCENTRATION, 1,600件）** — `MANAGEMENT_JUDGMENT_REVIEW`。経営方針そのもの。
- **F-005（A08, 343件）** — C03 適用後に件数が増えており、まず「増加が悪化なのか可視化なのか」を切り分ける必要がある。切り分け前に修正を当てると、Cycle 1 の C02 と同じ誤りを繰り返す。

C02 で「もっともらしいが実測で棄却された仮説」を1件経験しているため、根拠が固まらないまま追加のサイクルを回すことはしなかった。

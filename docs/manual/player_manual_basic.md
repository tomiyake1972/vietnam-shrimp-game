## 0. まず30秒で全体像

あなたは**ベトナムのエビ加工会社の経営者**です。

- 同じ市場で**5社**が競争します。あなた以外の4社はコンピュータ（Standard AI）が動かします。
- **1ターン = 1四半期（3か月）**。全部で**32ターン = 8年**です。
- 毎ターン、7つの画面で意思決定を入力して**提出**します。全社が提出すると、GM（進行役）がターンを進め、結果が出ます。
- 勝敗は **TSV（総株主価値）** で決まります。配当の積み上げと、会社そのものの価値の合計です。

やることは、この輪をうまく回すことです。

```
原料を買う → 工場で加工する → 市場で売る → 代金を回収する → また原料を買う
     ↑                                                        │
     └──────────── 足りなければ借りる・増やす ←────────────┘
```

## 1. 最初に覚える7つの約束事

ここを誤解すると、ほぼ確実に損をします。順番に読んでください。

### 約束1：数量はすべて「HOSO換算トン」。歩留まりを考える必要はありません

このゲームの数量は、原料・在庫・生産能力・契約・販売量まで**すべて「HOSO換算トン」という1つの単位**です。

- **原料1トンを投入すると、完成品1トンができます**（HOSO・PD・VAPのいずれでも同じ）。
- 「PDは殻と頭を取るから目減りする」という物理的な重量減少は、**HOSO換算という単位にした時点ですでに織り込まれています**。そこへさらに歩留まりを掛けると二重に減らしてしまうので、ゲームはそうしません。
- エンジンの設定値も `販売可能回収率 = 1.00`（HOSO・PD・VAPすべて）です。

> **つまり：数量の計算で歩留まり率を掛ける必要はありません。** 1,000トンの原料から1,000トンの製品ができる、と考えてください。
>
> 物理的な重量換算（HOSO原料100トン → PD 約54物理トン）は参考情報として存在しますが、契約・在庫・能力の数量には一切使われません。

**ただし、品質不良による損失は別にあります。** 稼働率を上げすぎる・残業を増やす・臨時工を増やすと、格落ち・再加工・廃棄が発生して実際に数量と売上が減ります（→ §10 品質）。これは「歩留まり」ではなく「品質の失敗」です。

### 約束2：営業して取った注文の納期は「翌四半期」

- いま営業して成約した契約の**納期は、必ず次の四半期**です。
- **ただし、当期中に出荷できる分は当期に納入できます。** 在庫や当期の生産でまわせるなら、納期を待たずに納めます。
- 受注残（まだ納めていない契約）も同じで、納期が先のぶんでも在庫があれば当期に出荷されます。

> **つまり：受注残と「いま新しく売る分」は、同じ在庫・同じ生産能力を取り合います。**
> だから販売画面の「販売可能量（上限）」は、受注残を全額差し引いた数字になっています。

### 約束3：お金が入るタイミングと出るタイミングがずれます

| 項目 | タイミング |
| --- | --- |
| 売掛金の回収（売上の入金） | 売った**1四半期後** |
| 国内買付の支払い | **その四半期に即時** |
| 輸入の支払い | 発注の**1四半期後** |
| 法人税 | 税率 20% |

国内で原料を買うと現金はすぐ出ますが、売上の入金は1四半期後です。**黒字でも現金が足りなくなります。** これがこのゲームで最初につまずく点です。

### 約束4：価格は自分で決められますが、範囲があります

- 販売価格：市場の基準価格の **0.5倍〜2.0倍** の範囲で、提示価格を上下できます。
- 国内原料の入札価格：市場価格の **0.5倍〜2.0倍** の範囲。
- 1社が1つの市場・商品で取れる成約は**最大35%**までです（独占はできません）。
- 顧客には「どの会社からも買わない」という選択肢もあります（外部選択肢のウェイト 0.35）。高すぎれば誰も買いません。

### 約束5：市場は5つ、商品は3つ

- 商品：**HOSO（殻付き）／PD（むき身）／VAP（加工品）**
- 市場：**CN／US／EU／JP／OTHER**。性格がはっきり違います。

| 市場 | 性格 |
| --- | --- |
| **US** | 大規模市場。PD需要が厚く、VAPも中期的に伸びる（成熟時 PD 38% / VAP 26%） |
| **JP** | 高付加価値市場。初期からVAP比率が最も高く（10%）、成熟時VAP30%まで伸びる。**品質・納期の要求が厳しい** |
| **EU** | 中規模・品質重視。PD/VAPの伸びはUS/JPよりやや遅い（加速開始 Turn 10） |
| **CN** | 最大の数量市場だがHOSO中心（初期VAP 1%）。付加価値化の立ち上がりが最も遅い（加速開始 Turn 16〜22） |
| **OTHER** | その他アジア等。HOSO主体で**価格感応度が高い** |

同じVAPでも、JPとCNでは売れ方がまったく違います。商品と市場の組み合わせで考えてください。

### 約束6：入力欄の初期値は「AIの提案」です

画面を開くと、すべての入力欄にAIが考えた数値が入っています。

- そのまま提出することもできます。研修ではまずそうしても構いません。
- ただし初期値は**実行可能な範囲に自動で調整済み**です。調整した場合は画面の先頭に「初期値を実行可能な範囲に調整しました」と、AIの提案値・調整後の値・その理由が出ます。
- **調整済みでも最適ではありません。** AIは在庫や受注残を細かく見ていません。必ず「販売可能量（上限）」の表を確認してください。

### 約束7：一度提出したら、そのターンは直せません

同じターンに2回提出することはできません。間違えたらGMに申し出てください。
提出前の下書きはページを再読み込みすると消えます（確定済みの意思決定は消えません）。

## 2. 商品のこと

| | HOSO | PD | VAP |
| --- | --- | --- | --- |
| 中身 | 殻付き・頭付き | むき身 | 衣付け・味付け等の加工品 |
| 加工費 | **350 USD/トン** | **520 USD/トン** | **780 USD/トン** |
| 価格プレミアム（基準） | — | **+18%** | **+55%** |
| ワーカー1人の処理能力 | **6.0 t/四半期** | **5.0 t/四半期** | **2.0 t/四半期** |
| 営業の手間（工数換算） | **×1.0** | **×1.2** | **×3.0** |

読み方：

- **VAPは高く売れますが、手間が3倍かかります。** 同じ1トンを売るのに営業工数が3倍、作るのに人手が3倍必要です。
- PDはHOSOより少し高く売れて、少し手間が増える程度です。
- 価格プレミアムは「基準」です。実際は稼働率・品質スコアによって変動します（稼働率が高いほどプレミアムは下がる方向）。

完成品の**消費期限は4四半期**です。それを過ぎた在庫は廃棄損になります。

## 3. あなたの会社（5社の初期条件）

会社は5社あり、得意分野が違います。あなたが担当する会社の強みと弱みを最初に把握してください。

| | **BAL**<br>バランス型 | **MASS**<br>大量生産・価格競争 | **JPQ**<br>日本・品質志向 | **VAP**<br>VAP特化 | **CONSV**<br>保守的・財務慎重 |
| --- | --- | --- | --- | --- | --- |
| 常用ワーカー | 6,000人 | **9,000人** | 5,500人 | 6,500人 | 4,500人 |
| 技能 HOSO | 0.85 | **0.90** | 0.60 | 0.50 | 0.80 |
| 技能 PD | 0.80 | 0.60 | **0.95** | 0.65 | 0.75 |
| 技能 VAP | 0.75 | 0.50 | 0.70 | **0.95** | 0.70 |
| 名目 HOSO能力 | 8,000t | **12,000t** | 8,000t | 8,000t | 8,000t |
| 名目 PD能力 | 7,000t | 6,000t | **8,000t** | 6,000t | 7,000t |
| 名目 VAP能力 | 5,000t | 4,000t | 5,000t | **6,000t** | 4,000t |
| 共通前処理 / 凍結・包装 | 30,000t | 30,000t | 30,000t | 30,000t | 30,000t |
| 営業人員 | 60人 | 60人 | 60人 | 60人 | 60人 |
| 調達人員 | 12人 | **20人** | 10人 | 10人 | 8人 |
| 自社養殖能力 | 4,000t | 4,000t | 4,000t | 4,000t | 4,000t |
| 初期原料在庫 | 3,000t<br>@$4.20/kg | 5,000t<br>@$4.00/kg | 2,500t<br>@$4.30/kg | 2,500t<br>@$4.30/kg | 3,000t<br>@$4.10/kg |
| 出勤率 | 95% | 95% | 95% | 95% | **97%** |

読み方：

- **技能水準の差は大きい。** VAP特化水産（VAP）のVAP技能0.95に対し、大量生産水産（MASS）は0.50。同じVAP 1,000トンを作るのに、VAPは約**554人**、MASSは約**1,053人**のワーカーが必要です（1人あたり 2.0t × 技能 × 出勤率95%）。
- **技能の低い商品を主力にすると、同じ量を作るのに人手が倍かかります。** まずは自社の技能が高い商品を軸に組むのが安全です。
- 共通前処理・凍結・包装は5社とも同じ30,000t（実効25,650t）です。ここが詰まることは序盤はありません。

## 4. 1ターンの流れ

### 7つの画面

| 画面 | 何を決めるか |
| --- | --- |
| **INFO** | 入力しません。市場情報・自社の状態・前期のふりかえりを読む画面 |
| **SALES** | 市場×商品ごとの販売希望量・価格調整、営業人員の市場別配置、営業の採用・減員 |
| **PRODUCTION** | 商品ごとの生産量と生産優先順位 |
| **WORKER** | 工場の常用ワーカー人数・臨時ワーカー・残業率 |
| **PROCUREMENT** | 国内買付・輸入発注・自社養殖の池入れ |
| **INVESTMENT** | 設備投資の提案、VAP商品開発費 |
| **FINANCE** | 借入の申請・早期返済、配当 |

### 進め方

1. INFOで状況を把握する
2. SALES → PRODUCTION → WORKER → PROCUREMENT → INVESTMENT → FINANCE の順に入力する
3. 「意思決定を確認」を押して、最終確認画面で内容を見る
4. 「この内容で提出」を押す
5. GMが全社の提出を確認してターンを進めるまで待つ（画面は開いたままで、自動的に次のターンに切り替わります）

> **おすすめの順番は SALES から。** 「いくら売るか」が決まらないと、作る量も買う原料も決まりません。

## 5. 売る（SALES）

### 営業人員ができること

営業人員には**2つの効き方**があります。混同しないでください。

**(1) 会社全体の処理能力（さばける量の上限）**

会社の営業組織全体で、1四半期にさばける量に上限があります。

```
処理能力（営業工数トン／四半期） = 1,000 + 95,000 × 人数 ÷ (人数 + 190)
```

| 営業人員 | 処理能力 | 1人あたり平均 |
| --- | --- | --- |
| 10人 | 5,750 工数t | 575 工数t |
| 20人 | 10,048 工数t | 502 工数t |
| 30人 | 13,955 工数t | 465 工数t |
| 40人 | 17,522 工数t | 438 工数t |
| **60人（開始時）** | **23,800 工数t** | **397 工数t** |
| 80人 | 29,148 工数t | 364 工数t |
| 100人 | 33,759 工数t | 338 工数t |
| 150人 | 42,912 工数t | 286 工数t |
| 200人 | 49,718 工数t | 249 工数t |

**「工数トン」は商品で重みが違います。**

```
営業工数 = HOSO数量 × 1.0 + PD数量 × 1.2 + VAP数量 × 3.0
```

例：HOSO 5,000t ＋ PD 3,000t ＋ VAP 1,000t を売るなら
`5,000 + 3,600 + 3,000 = 11,600 工数t` が必要です。営業20人（10,048工数t）では足りません。

> **増員の効果は逓減します。** 「増やした1人が何工数t分の能力を足すか」で見ると、
> 10人→20人では **430 工数t/人**、60人→80人では **267 工数t/人**、100人→150人では **183 工数t/人**。
> 一方で給与は1人8,000ドルのまま人数に比例します。**増員の前に、この表で「あと何工数t増えるか」を必ず確認してください。**

**(2) 市場ごとのカバレッジ（成約競争力の一因子）**

その市場に何人配置したかで、顧客からの見え方が変わります。

| その市場の営業人員 | カバレッジ |
| --- | --- |
| 0人 | 15.0% |
| 2人 | 36.3% |
| 4人 | 49.0% |
| 6人 | 57.5% |
| 10人 | 68.1% |
| 20人 | 80.4% |
| 30人 | 85.8% |

0人でも15%残るのは「既存顧客がいる」という設定です。こちらも逓減します。

> **1人は1つの市場にしか配置できません。** ただし同じ市場のHOSO/PD/VAPは同じ営業チームが兼務します（市場ごとに1つの人数を入れます）。配置人数の合計が保有人数を超えることはできません。

### 営業人員のコスト

| 項目 | 金額・条件 |
| --- | --- |
| 給与 | **8,000 USD／人・四半期** |
| 採用の上限 | 1四半期に **max(3人, 現員の30%)** まで |
| 採用の反映 | 採用した人が働けるのは**次の四半期から**（当期の配置可能人数は増えません） |
| 減員の反映 | 人数が減るのは**次の四半期から**（当期は配置・給与の対象のまま） |
| 退職金 | **16,000 USD／人**（四半期給与2四半期分）。減員を決めた四半期に一括で販管費・現金支出 |
| 採用と減員 | 同じ四半期に両方を入力することはできません |

> **減員は無料ではありません。** 減員を決めた四半期は、退職金16,000ドルに加えてその人の給与8,000ドルも満額かかります（1人あたり24,000ドル）。給与が下がるのは次の四半期からです。
>
> 採用上限を超えた入力は**提出の時点で止まります**。その場で直して再提出できます。

### 成約がどう決まるか

顧客はあなたと他4社を比べて選びます。比べる要素は、Runの販売モデルによって変わります。

- **従来市場モデル**：価格・営業カバレッジ・顧客関係・品質・納期信頼性のウェイト付き合成
- **三層顧客価格モデル**：顧客を「価格重視層・標準層・プレミアム層」の3層に分け、層ごとに重視する要素が違う（価格重視層は価格に敏感、プレミアム層は品質と差別化に敏感）

**いまのRunがどちらで、どの要素がどれだけ効くかは、INFOタブの「市場情報」→「参考価格・需要ウェイト・営業工数」に表示されます。** 必ずそこを見てください。

### 「販売可能量（上限）」の読み方

SALES画面の先頭に、商品ごとの上限が出ます。

```
納められる上限   = 完成品在庫 ＋ 当期の実効加工能力
販売可能量（上限）= 納められる上限 − 受注残
```

- **赤い警告**：「納められる上限」を超えている → その量は今期どうやっても納められません
- **黄色い警告**：上限内だが受注残を先に納めると足りない → 納期遅れのリスク

これは**目安**です。実効加工能力は今の原料在庫を前提にした見込みで、当期の買付・輸入到着は含みません。提示した量がそのまま成約するわけでもありません。

## 6. 作る（PRODUCTION）

### 5つの能力プール

| プール | 意味 |
| --- | --- |
| 共通前処理能力 | 原料をどれだけ投入できるか（**原料投入量**の上限） |
| HOSO加工能力 | HOSOをどれだけ作れるか（**完成品**の上限） |
| PD加工能力 | 同じくPD |
| VAP加工能力 | 同じくVAP |
| 凍結・包装能力 | 凍結・包装できる量（**完成品**の上限） |

### 名目能力と実効能力

```
実効能力 = 名目能力 × 基準稼働率 0.90 × 設備利用可能率 0.95 = 名目能力 × 0.855
```

| 名目 | 実効 |
| --- | --- |
| 30,000t | 25,650t |
| 8,000t | 6,840t |
| 7,000t | 5,985t |
| 5,000t | 4,275t |

> **画面で「名目」と「実効」の両方が出ます。計画は実効能力で立ててください。** 名目能力で計画すると約15%作れません。

### 制約が当たる順番

希望量は、この順に削られていきます。

1. **原料在庫**（会社全体の共有・原料投入量ベース）
2. **工場共通処理能力**（工場単位の共有・原料投入量ベース）
3. **凍結・包装能力**（完成品ベース）
4. **商品別加工能力**（工場×商品・完成品ベース）
5. **人員**（配置したワーカーで処理できる量）

**どの段階で削られたかは「減産の原因」として画面に出ます。** 原料不足なら買付を増やす、人員不足ならワーカーを増やす、と対処先が変わります。

### 生産優先順位

商品ごとに優先順位（数字）を入れます。

- 数字が小さいほど優先されます。
- 同じ優先度の商品は、希望量に比例して配分されます（先着順ではありません）。
- 上位優先度で使い切らなかった能力だけが下位へ回ります。

### 冷凍・冷蔵保管能力について（注意）

**「凍結・包装処理能力」と「冷凍・冷蔵保管能力」は別のものです。**

- 凍結・包装処理能力 … その四半期に凍結・包装できる数量（トン／四半期）。**生産量の上限として実際に働きます。**
- 冷凍・冷蔵保管能力 … 同時に保管できる在庫量（トン）。四半期あたりの処理量ではありません。

現時点では、保管能力は**状態と空き容量の表示までが実装**されています。保管能力を超えたときに入庫を拒否する・在庫を自動廃棄する・外部倉庫へ振り替えるといった強制的な制約は**エンジンへ未接続**です。

## 7. 人を配置する（WORKER）

### ワーカー1人が処理できる量

```
1人あたり処理量 = 基礎効率 6t ÷ 労働集約度 × 出勤率 × 商品別技能水準 × 残業係数
```

| 商品 | 労働集約度 | 1人あたり（技能1.0・出勤率1.0・残業0） |
| --- | --- | --- |

| PD | ×1.2 | **5.0 t/四半期** |
| VAP | ×3.0 | **2.0 t/四半期** |

- 出勤率の初期値は **95%**（CONSVのみ97%）
- 技能水準は**会社・商品ごとに大きく違います**（下表）。得意な商品を作るほうが人手が少なく済みます

### コストと臨時・残業

| 項目 | 金額・条件 |
| --- | --- |
| 常用ワーカー給与 | **1,000 USD／人・四半期** |
| 臨時ワーカー費用 | **800 USD／人・四半期**（処理能力は **3.5 t/人**＝常用より低い） |
| 残業の上限 | **30%** まで |
| 残業の割増 | 給与 **1.5倍** |
| 残業の効率 | 追加分の効率は **0.5**（残業率30%でも処理量は+15%） |

> **残業と臨時工は「安い増産手段」ではありません。** 残業は割増1.5倍で効率0.5、臨時工は能力が常用の約6割です。しかも**どちらも品質リスクを上げます**（→ §10 品質）。

## 8. 原料を買う（PROCUREMENT）

原料の入手経路は3つです。

### (1) 国内買付（ベトナム国内）

- **5社の入札で競争配分されます。** 希望量を出しても、そのまま買えるわけではありません。**安く買い叩こうとすると他社に取り負けます。**
- 農家から見た競争力は「価格40% ／ 調達カバレッジ25% ／ 農家との関係20% ／ 支払の確実性15%」で決まります。高く提示するほど多く取れますが、原料費が上がります。
- 入札価格は市場価格の **0.5倍〜2.0倍** の範囲。
- 1社の買付シェア上限は **35%**（買い占めはできません）。
- 支払いは**その四半期に即時**（現金がすぐ出ます）。
- 調達人員を増やすと、処理できる量と農家からの見え方が改善します（調達人員の給与 **7,000 USD／人・四半期**）。
- **最初の四半期（Turn 1）だけは特別** です。前四半期がないため市場の清算価格がまだありません。代わりに「国内原料参考価格」が示され、**この価格以上を提示すれば通常条件で必要量を購入できます**（供給量・調達処理能力・シェア上限35%の範囲内）。Turn 2以降はこの保証はありません。

### (2) 輸入

- **リードタイム2四半期**。発注した原料が使えるのは2四半期後です。
- コストは「産地FOB価格 ＋ 運賃 0.15 USD/kg ＋ 関税 5% ＋ 保険・荷役 0.05 USD/kg」。
- 支払いは発注の**1四半期後**。
- 産地はエクアドル（EC）・インド（IN）・インドネシア（ID）・ベトナム（VN）。開始時のHOSO FOB価格は EC 4.70／IN 5.25／ID 5.45／VN 5.60 USD/kg。

### (3) 自社養殖

- 池入れ量と「養殖強度」「バイオセキュリティ水準」を決めます。
- 期待生産量：

```
期待生産量 = 池入れ量 × (1 ＋ 0.50 × 養殖強度)
```

例：池入れ 4,000t × (1 + 0.50 × 0.60) = **5,200t**

- 単価は **3.2 USD/kg**（固定）。
- **養殖強度を上げると歩留まりは最大50%増えますが、疾病に弱くなります。** バイオセキュリティ水準を上げると疾病の影響を最大70%まで抑えられます。実際の収穫量は収穫時の疾病圧力で決まるため、上の期待生産量は**確定値ではありません**（最悪の場合、生残率は10%まで落ちます）。
- 自社養殖能力の上限は5社とも **4,000t**。

### 原料の期限

原料は**4四半期**を過ぎると使えなくなります（期限切れ廃棄損）。

### 「原料在庫」の2つの意味（間違えやすい点）

| 画面 | 意味 |
| --- | --- |
| INFOタブ「原料在庫 合計」 | 使用可能 ＋ 輸送中 ＋ 養殖中 の**全部** |
| ふりかえり「期末の原料在庫」／Inventoryタブ | **使用可能な分だけ**（輸送中・養殖中を含まない） |

数字が違っていても不具合ではありません。**今期の生産に使えるのは「使用可能な分」だけ**です。

- $0を選んでも、スコアは毎四半期一定割合で中立値50へ向かって減衰します（投資を止めると徐々に下がります）。

## 10. 品質

品質は「作りすぎ・無理な操業」で悪化します。

**リスクを上げる要因**（重み付き合成）

| 要因 | 重み |
| --- | --- |
| 稼働率（80%超から効きはじめる） | 0.35 |
| 残業率 | 0.20 |
| 臨時ワーカー比率 | 0.15 |
| 生産の複雑さ（商品ミックス） | 0.10 |
| 原料の古さ | 0.10 |
| 生産量の急な立ち上げ | 0.10 |

**悪化したときに起きること**

- 不適合が最大 **8%** まで発生し、その内訳は **格落ち45%／再加工25%／廃棄30%**
- 格落ち品は数量は減りませんが、**契約単価の25%が売上から控除**されます
- 再加工費は **200 USD/トン**
- 廃棄は数量そのものが失われます
- まれに重大品質事故が起きます（基礎確率0.2%、リスクが高いと最大8%）。顧客信頼と品質スコアが大きく下がります

**品質スコアと納期信頼性は「下がりやすく、上がりにくい」** 設定です（品質スコア：下落の反映係数0.20／上昇0.08）。一度落とすと回復に時間がかかります。

### 借入

```
金利（年率） = ベース 4.0% ＋ 信用区分スプレッド ＋ 各種上乗せ
四半期の利息 = 残高 × 年率 ÷ 4
```

| 信用区分 | スプレッド（年率） | 通常融資の年率 | 四半期の利率 | 自己資本倍率の上限 |
| --- | --- | --- | --- | --- |
| **A** | +2.0% | **6.00%** | 1.500% | 1.5倍 |
| **B** | +3.5% | **7.50%** | 1.875% | 1.1倍 |
| **C** | +5.0% | **9.00%** | 2.250% | 0.75倍 |
| **D** | +7.0% | **11.00%** | 2.750% | 0.4倍 |
| **E** | +9.0% | **13.00%** | 3.250% | 0（新規融資停止） |

上乗せ：財務制限条項違反 +1.5%／延滞履歴 +2.0%／借換 +0.5%／8四半期超の長期 +0.5%／緊急融資 +10.0%

> 開始時の信用スコアは **65点**（区分B相当の入口）で、区分の境目は **A 80点以上／B 65点以上／C 50点以上／D 35点以上／E それ未満**。
> 初期借入は区分C相当の **年9.00%** で設定されています（短期は4四半期・満期一括、長期は20四半期・元金均等）。
> **信用区分が1段下がると、同じ借入でも利息が年1.5〜2.0ポイント増えます。**

**借入余力の決まり方**

```
担保ベースの上限 = 売掛金×0.7 ＋ 使用可能原料×0.4 ＋ 輸送中原料×0.15 ＋ 完成品×0.3
収益ベースの上限 = EBITDA相当 × 2.0
信用区分の上限   = 自己資本 × 信用区分の倍率

総枠 = min( max(担保ベース, 収益ベース), 信用区分の上限 )
借入余力 = 総枠 − すでに借りている残高
```

> **信用区分がAでも、総枠を既存借入が使い切っていれば余力は$0です。** 信用区分は「自己資本倍率の上限」にしか関与しません。画面にこの内訳が表示されます。

**審査のタイミング**：申請したその四半期に審査され、承認された額はその四半期の資金として使えます。ただし審査は当四半期の業績が確定したあとに行われるため、**実行額は申請額と異なることがあります**。

**最初の四半期（Turn 1）は利息が発生しません。** 融資は実行した四半期には利息が付かない決まりで、初期借入もゲーム開始の四半期に実行された扱いになるためです。残高があるのに利息が0なのは不具合ではありません。**元本の返済はTurn 1から発生します。**

### 配当

```
配当可能額 = min( 現金, 分配可能利益 )
```

- 申請額が配当可能額を超えると**全額が拒否**されます（一部実行ではありません）。
- **Turn 1の配当可能額は$0です。** まだ1四半期も利益が確定していないため、現金があっても配当できません。
- 配当は**TSVに直接効きます**（→ §12 成績）。ただし出した現金は事業に使えなくなります。

### 緊急融資

資金が尽きたときの最後の手段です。FINANCE画面で「緊急融資も許容する」にチェックを入れておくと、資金不足になったときだけ自動的に実行されます。

- 金利は通常融資に **+10.0%** 上乗せ。信用区分別の年率は **A 16.0% / B 17.5% / C 19.0% / D 21.0% / E 23.0%**
- 期間は **2四半期**
- 上限は「担保の50%」または「3,000万USD」の小さい方

**通常融資の2〜3倍の金利です。** 使わないで済む計画を立ててください。

## 12. 成績（TSV = 総株主価値）

```
TSV = 配当価値 ＋ 現在の会社価値

配当価値     = Σ（各ターンの配当額 × 1.15^((評価ターン − 配当ターン) ÷ 4)）
会社価値     = 事業価値 ＋ 現金 − 負債
事業価値     = 直近3ターンの営業キャッシュフロー平均 × 4 × 6.1446
               （6.1446 = 10年・割引率10%の年金現価係数）
```

読み方：

- **配当は早く出すほど価値が増えます**（年率15%で複利評価）。ただし配当した現金は事業に使えません。
- **会社価値は「直近3ターンの営業キャッシュフロー」で決まります。** 最後の数ターンで稼ぐ力を落とすと、会社価値が一気に下がります。
- 評価はつねに「現在のターン」基準です。将来の利益を見込んだ値は一切入りません。
- TSVランキングは **Turn 12** から公開されます（それ以前は「まだ出せません」と表示されます）。

## 13. 最初の3ターンでやること

### Turn 1

1. **INFOを読む** — 自社の工場能力（名目と実効）、ワーカー数、営業人員、現金、借入、受注残、原料在庫を確認する
2. **INFOの「市場情報」を開く** — 国内原料参考価格、市場ごとの需要と価格、成約競争力のウェイトを確認する
3. **SALESの「販売可能量（上限）」を見る** — 商品ごとに今期いくらまで売れるかを把握する
4. **営業人員の配置を決める** — 60人をどの市場に振るか。工数換算（VAPは3倍）を忘れずに
5. **PRODUCTIONは実効能力で計画する** — 名目で計画しない
6. **PROCUREMENT** — 国内買付は参考価格以上を提示する。輸入は2四半期後に届くことを意識する
7. **FINANCE** — 現金の出入りのズレ（国内買付は即時支払／売上は1四半期後入金）を確認する。Turn 1は配当できない

### Turn 2

1. **Overviewの「前Turnのふりかえり」を読む** — 提示した量のうちどれだけ成約したか、どこで減産したか
2. **減産の原因を確認する** — 原料不足／設備能力不足／人員不足のどれか
3. **成約率を見る** — 提示に対して何割が成約したか。これが次の計画の基礎になります
4. **在庫を確認する** — 作った量と納めた量の差が在庫になります。積み上がっていないか

### Turn 3

1. **借入余力の内訳を見る**（Turn 2から表示されます）— 何が上限を決めているか
2. **品質スコアと納期信頼性を確認する** — 下がっていたら稼働率・残業・臨時工を見直す
3. **ここまでの3ターンの傾向から、自社の戦略を決める** — 量で勝つのか、付加価値で勝つのか

## 14. よくある失敗

| 失敗 | なぜ起きるか | 対策 |
| --- | --- | --- |
| **黒字なのに現金が尽きる** | 国内買付は即時払い、売上回収は1四半期後 | 買付額と現金残高を必ず並べて見る。借入は申請した四半期に使える |
| **名目能力で計画して約15%作れない** | 実効能力 = 名目 × 0.855 | PRODUCTION画面の「実効」の数字で計画する |
| **提示した量が成約せず在庫が積み上がる** | 生産を「提示量」に合わせているが、市場は提示の全部を取らない | 前期の成約実績を見て生産量を決める |
| **VAPを増やしたら営業も人も足りなくなった** | VAPは営業工数3倍・必要人数3倍 | 工数換算と人数換算で先に確認する |
| **受注残を忘れて売りすぎ、納期遅れになる** | 受注残と新規販売は同じ在庫・能力を取り合う | 「販売可能量（上限）」（＝上限−受注残）で判断する |
| **営業を増やしすぎて給与が重くなる** | 給与は人数に比例、能力は逓減 | 増員前に処理能力の表で「あと何工数t増えるか」を確認する |
| **減員したら思ったより高くついた** | 退職金16,000＋当期給与8,000＝1人24,000ドル | 減員は慎重に。人数が減るのは翌期から |
| **残業・臨時工で無理に増産して品質が落ちた** | 稼働率・残業・臨時比率が品質リスクを上げる | 品質スコアは下がりやすく上がりにくい。無理をしない |
| **輸入が間に合わない** | リードタイム2四半期 | 2四半期先の必要量から逆算して発注する |
| **投資の効果が出る前に資金が尽きた** | 工期＋準備期間で最大6四半期かかる | 支払いスケジュールと効果が出る時期を確認する |

| **実効能力** | 名目 × 基準稼働率0.90 × 設備利用可能率0.95 = 名目 × 0.855。計画はこれで立てる |
| **受注残（backlog）** | 成約したがまだ納めていない量。在庫・生産能力を新規販売と取り合う |
| **納期超過（overdue）** | 納期を過ぎても納めていない量。納期信頼性が下がる |
| **営業工数トン** | 営業の負荷に換算した量。HOSO×1.0 ＋ PD×1.2 ＋ VAP×3.0 |
| **カバレッジ** | その市場に配置した営業人員から決まる成約競争力の一因子（0〜1） |
| **格落ち** | 品質不良で等級が下がること。数量は減らないが契約単価の25%が売上控除になる |
| **分配可能利益** | 配当に回せる利益。配当可能額 = min(現金, 分配可能利益) |
| **信用区分** | A〜Eの格付け。金利スプレッドと自己資本倍率の上限を決める |
| **TSV** | 総株主価値。配当価値 ＋ 会社価値。これで順位が決まる |
| **Standard AI** | あなた以外の4社を動かすコンピュータ。入力欄の初期値もこのAIの提案 |

## 付録：現時点で実装されていないもの

研修で「あるはず」と思って探さないように、明記しておきます。

- **排水・環境関連**：排水処理能力という状態量、環境事故、行政処分・罰金、環境監査。排水・環境設備への投資に効果はありません。
- **冷凍・冷蔵保管能力の強制**：保管能力を超えたときの入庫拒否・自動廃棄・外部倉庫への振替・強制販売。表示までの実装です。
- **純売上高の商品別内訳**：損益計算書は会社合計のみです。商品別の売上は「未実装」と表示されます。
- **営業人員の自然減（離職）・採用の一時費用**：ありません。
- **解雇による評判・顧客関係の悪化**：ありません。コストは退職金と当期給与だけです。

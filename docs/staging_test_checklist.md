# ShrimpX テスト環境確認チェックリスト

`docs/staging_environment.md` の手順に沿ってテスト環境を構築したら、このチェックリストで実際の動作を確認してください。すべてにチェックが入った状態で、初めて本番へのマージ（19章「本番へコードを反映する流れ」）に進みます。

## 環境表示

- [ ] テスト環境のURLを開くと、オレンジ色の環境バナーが表示される
- [ ] バナーに表示されている環境名（staging等）が、意図した環境と一致している
- [ ] 本番環境のURLを開くと、バナーが表示されない
- [ ] テスト環境のURLと本番環境のURLが明確に異なることを確認した

## Redis分離

- [ ] テスト環境でゲームを作成できる
- [ ] テスト環境で作成したゲームが、本番環境の過去ゲーム一覧に表示されない
- [ ] 本番環境の既存ゲームが、テスト環境の過去ゲーム一覧に表示されない
- [ ] （Upstash管理画面で確認できる場合）テスト用データベースと本番用データベースの中身が別々になっている

## テストゲーム作成

- [ ] テスト環境で作成したゲームに「TEST GAME」の表示が出る
- [ ] ゲームに乱数シード（Seed）が表示される
- [ ] 本番環境でゲームを作成した場合、「TEST GAME」表示が出ない

## GM操作

- [ ] GM画面から社A〜社Eをそれぞれ操作できる
- [ ] AI担当に設定した会社も、GM画面から操作できる
- [ ] GM操作を行っても、その会社の担当設定（AI担当かどうか）が変わらない
- [ ] 本番環境ではGM操作のボタン（🎮 テスト操作セクション）が表示されない

## 提出状況

- [ ] 各社の提出状況（未提出／提出済み）が正しく表示される
- [ ] 同じ会社が同じ四半期に2回提出すると「再提出済み」と表示される
- [ ] 提出状況の画面が自動的に更新される（5秒間隔のポーリング）
- [ ] 手動更新ボタンで即座に最新状況を取得できる
- [ ] 過去に作られた古い形式のゲームでも、提出状況画面がエラーにならず表示される

## ターン処理

- [ ] 全社提出後、ターン処理を実行できる
- [ ] ターン処理後、次の四半期に進み、提出状況が「0/5」に戻る
- [ ] 未提出の会社があっても、既定値でターン処理を実行できる

## テストゲーム初期化

- [ ] 管理トークンを入力しないと初期化を実行できない
- [ ] 誤った管理トークンで初期化を試みるとエラーになる
- [ ] 正しい管理トークンで初期化を実行できる
- [ ] 初期化後、タイトル・担当設定・乱数シード・作成日時が変わっていない
- [ ] 初期化後、年・四半期が最初の状態に戻る
- [ ] 初期化後、意思決定・ターン結果が削除されている
- [ ] 初期化前に保存したスナップショットが、初期化後も一覧に残っている

## テストゲーム複製

- [ ] 「現在の状態」を選んで複製すると、複製先に現在の年・四半期・履歴が引き継がれる
- [ ] 「初期状態」を選んで複製すると、タイトルと担当設定だけが引き継がれ、それ以外は初期化されている
- [ ] 「同じシード」を選ぶと、複製先のシードが複製元と一致する
- [ ] 「新しいシード」を選ぶと、複製先のシードが複製元と異なる
- [ ] 複製後、複製元のゲームの内容が変わっていない
- [ ] 複製されたゲームが「TEST GAME」として作られている

## スナップショット

- [ ] ラベルを付けてスナップショットを保存できる
- [ ] 保存したスナップショットが一覧に表示される
- [ ] スナップショットを21件以上保存すると、最も古いものが自動的に削除され、20件に保たれる
- [ ] 「この状態に戻す」を実行すると、実行前の状態が「復元前の自動保存」として自動的に保存される
- [ ] スナップショットから復元すると、選択した時点の年・四半期・会社状態に戻る
- [ ] 復元後もゲームコード・テストゲームかどうかの情報が、復元先ゲームの元の値のまま変わらない
- [ ] スナップショットを個別に削除できる

## テストゲーム削除

- [ ] 削除確認欄に何も入力しない状態では削除ボタンが押せない
- [ ] ゲームコードと異なる文字列を入力した状態では削除ボタンが押せない
- [ ] 正しいゲームコードを入力すると削除ボタンが押せるようになる
- [ ] 削除を実行すると、そのゲームが一覧から消える
- [ ] 削除を実行しても、他のゲームが一覧から消えたり内容が変わったりしない

## 本番環境での防御

- [ ] 本番環境でテスト環境の管理機能（テストゲーム管理セクション）が表示されない
- [ ] 本番環境で管理系APIに正しい管理トークンを送っても、操作が拒否される
- [ ] 本番環境で作成したゲームは常に「テストゲームではない」扱いになる
- [ ] 本番環境と、テスト環境のデータが混ざっていない

## 画面サイズ

- [ ] PC相当の画面幅で、GM画面・意思決定画面が横スクロールせずに表示される
- [ ] iPad相当の画面幅で、同様に確認できる
- [ ] スマートフォン相当の画面幅で、同様に確認できる

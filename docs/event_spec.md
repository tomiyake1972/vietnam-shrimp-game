## 確認結果

`main`ブランチおよび`claude/turn-processing-engine`ブランチの`app/`配下全体を以下のキーワードで全文検索した（大文字小文字を区別しない）：

`event`, `イベント`

**該当する実装は1件も存在しなかった。** ランダムイベント、市場価格変動、天候・災害、疫病、規制変更、為替変動など、四半期ごとに発生しうる外部要因をモデル化したコード・データ構造・UI文言は、リポジトリ内のどこにも存在しない。

市場価格（`docs/finance_spec.md` §5）・原料調達価格（同§3）はいずれも`app/lib/gameEngine.ts`内の固定定数であり、ゲームの進行や年度によって変動しない。

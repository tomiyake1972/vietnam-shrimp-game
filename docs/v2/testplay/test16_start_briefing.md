## 0. 最初に: Test15はそのままです

**Test15の環境・保存データには一切触れていません。** 今回追加した市場進化の挙動は
すべて `config.marketEvolution` という新しい設定グループで明示的にONにしたラボだけに
効きます。既定はすべてOFFで、既存のTest15ラボは従来とまったく同じ数値で動きます。

Test16は**別のラボ**として新規に作成します。Test15（機能の動作確認：入力・保存・
Excel・UI）とは目的が違います。

## 1. Test16の目的

Test15が「新機能がちゃんと動くか」の確認だったのに対し、Test16は
**「PD/VAPを中長期戦略の中心に据えた市場が、経営判断のゲームとして成立しているか」**
を確かめるものです。具体的には次の6点。

1. **需要が伸びる** — 世界需要が時間とともに成長する。
2. **商品構成が高度化する** — 市場ごとに違う速さでHOSOからPD、さらにVAPへ移る
   （日本が最も早く、米国が続き、中国はHOSO中心の期間が最も長い）。
3. **PD/VAPの価格が動く** — 加工プレミアムが需給で伸び縮みする。
4. **ベトナムの加工優位** — 原料はエクアドルの方が多いのに、加工能力があるベトナムが
   PD/VAP需要をより多く獲れる（序盤）。
5. **他産地の追い上げ** — 中盤以降にエクアドル・インドがPD加工へ参入し、
   プレーンPDのプレミアムが圧縮される。競争軸がVAP・営業力・品質へ移る。
6. **投資が回収できるか** — 新工場・PD省人化・VAP商品開発が、どの条件でなら
   採算に乗るのか。

## 2. Test15からの変更点（プレイに影響するもの）

| 変わったこと | 何が起きるか |
| --- | --- |
| 産地別の加工能力が時間とともに変わる | 序盤はベトナムのPD加工能力が他産地の10倍以上。turn14頃からエクアドルが急拡大する |
| 市場別の商品構成が時間とともに変わる | 日本のVAP需要はturn4から、米国はPDがturn6・VAPがturn12から加速する |
| 仕向市場ごとにPD/VAPの評価が違い、しかも時間で動く | 日本のVAPプレミアムが最も高く、中国が最も低い。需要構成が寄った市場ほどプレミアムが上がる |
| **営業能力の仕組みが変わった（最重要）** | 下記§3を必ず読んでください |
| ベトナムの加工優位が需要獲得へ効く | 加工能力を積んでいる分だけ、PD/VAP需要を多く狙える |
| 標準AIが市場を見て投資を判断する | 需要予測・能力不足・回収見込み・現金余力から投資の可否を決める |

## 3. 【最重要】営業の仕組みが変わりました

Test15までは「1市場あたり最大5,000トン」という**絶対量の上限**があり、営業員を
何人増やしてもそれ以上は売れませんでした。これがTest15の事前校正で見つかった
「新工場を建てても契約が増えない」「VAP投資が販売につながらない」の直接原因です。

Test16では次のように変わります。

- **販売処理能力**（どれだけの商談・契約を処理できるか）は**営業人数にほぼ比例**します。
  増員すればそのぶん売れるようになります。上限に張り付きません。
- さらに**市場の大きさ（対象需要）にも比例**します。需要が伸びれば売れる量も伸びます。
- **顧客開発能力**（VAP商品開発スコア・品質・顧客関係の蓄積）が、処理能力に
  **掛け算**で効きます。人数が多いほどこの掛け算の効果が大きくなります。
- **VAPは依然として営業工数が3倍かかります。** これは変えていません。ただし
  「人を増やせば解ける」ようになりました。

**したがって、VAP商品開発に投資するなら、営業人員の採用・再配置も同時に考えてください。**
どちらか片方だけでは効果が頭打ちになります（実測で、両方やった場合の効果は
片方ずつの効果の合計を上回ります）。

また、商品別の**販売優先度**を指定できるようになりました。営業能力が足りないときに
「HOSOを削ってでもVAPを守る」という選択ができます。

## 4. 初期状態

- 5社（BAL, MASS, JPQ, VAP, CONSV）。初期条件はTest15と同じ。
- 市場進化の機能フラグはすべてON（Test16ラボ作成時に設定）。
- 標準シナリオ長は32四半期（8年）。物語の弧（序盤の希少 → 中盤のPD黄金期 →
  終盤の他産地参入と圧縮）が一巡するのに必要な長さです。

## 5. 四半期ごとに見るもの

### 第1四半期でまず確認すること

1. Excelの新しい**「加工プレミアム」シート**を開く。★のついた3行（PDプレミアム比率・
   VAPプレミアム比率・VAP/PDプレミアム比）が今回の物語の中心指標です。
2. 各社の現金残高と営業人員数。営業増員の余地があるか。
3. 各工場の稼働率。低いなら、新工場を建てても意味がありません。

### 毎四半期記録してほしいもの

- **PDプレミアム比率 / VAPプレミアム比率 / VAP/PDプレミアム比**（加工プレミアムシート）
- PD世界稼働率・VAP世界稼働率（同シート）
- 価格変動の理由コード（`ECUADOR_PD_CAPACITY_EXPANSION` が出たら他産地参入の始まり）
- 各社の営業人員数・契約数量・生産量・稼働率
- 各社の現金残高（投資判断の前提になります）
- 行った投資（新工場・PD省人化・VAP商品開発の額）

## 6. 具体的に試してほしいこと

### 6-1. PD黄金期を捉える（turn 1〜14 あたり）

序盤はベトナムの加工優位が最大です。PDプレミアム比率が高い水準で推移します。

- **試すこと**: PD生産を厚めにし、営業人員をPDの主要市場（日本・米国）へ寄せる。
- **確認**: PDの契約数量と実現単価が伸びるか。稼働率が上がるか。
- **注意**: 稼働率が70%を超えないうちは新工場を建てないでください（後述）。

### 6-2. 他産地参入を見つける（turn 14〜20 あたり）

- **確認**: 「加工プレミアム」シートの PD世界稼働率が下がり始め、PDプレミアム比率も
  下がるはずです。理由コードに `ECUADOR_PD_CAPACITY_EXPANSION` と
  `PROCESSING_CAPACITY_OVERSUPPLY` が出ます。
- **注意**: PDの**絶対価格**は原料価格の上昇に引っ張られて上がり続けます。
  「安くなった」ようには見えません。**比率**で判断してください。
- **試すこと**: この局面でPD省人化投資を行い、コスト競争力で耐えられるか。

### 6-3. VAPへ軸を移す（turn 16以降）

- **試すこと**: VAP商品開発投資を継続しつつ、**同時に営業人員も増やす**。
  片方だけでは効果が出ないことを確認してください。
- **確認**: VAP/PDプレミアム比が拡大していくか。自社のVAP成約量が伸びるか。

### 6-4. 新工場を建てるなら

**建てる前に3つ揃っているか確認してください。**

1. 既存工場の稼働率が高い（70%以上が目安）
2. 需要が今後も伸びる見通しがある
3. 投資後も現金が安全水準を保てる

そして**必ず**、稼働開始後に (a) 新工場へワーカーを配置し、(b) 営業人員も増やして
販売計画を広げてください。実測では、工場だけ建てて営業を増やさないと、作った分が
在庫になって**累積純利益が3.5億USD悪化**しました。逆に両方揃えると営業だけの場合より
**約9,600万USD改善**します。

### 6-5. 壊しにいってほしいこと

- **需要が伸びる前に全部投資したらどうなるか**（開発側の検証では、これは何も
  投資しない場合よりさらに悪い結果になりました）。同じ結果になるか確かめてください。
- **営業人員をゼロに近づけたらどうなるか**。処理能力の下限（1市場200トン）に
  張り付くはずです。
- **VAP比率を極端に上げたらどうなるか**。営業工数3倍が効いて、他の商品が
  売れなくなるはずです。販売優先度でどこまで制御できるか試してください。
- **標準AIに任せきりにしたらどうなるか**。開発側の検証では、5社×3シードのうち
  10通りが何らかの新投資を採用し、期末現金は15通りすべて異なる値になりました
  （Test15の標準AI検証では全社が完全に同一の破綻結果でした）。

## 7. Excelダウンロード手順

Test15と同じです。管理者/GM用ページ（`/v2/company-lab`）から対象ラボを選び、
分析Excelをエクスポートします。シート構成に**「加工プレミアム」**が加わっています。

四半期ごとにエクスポートして保存しておくと、プレミアム比率の推移が後から追えます。

## 8. 開発側が把握している未解決の課題

プレイ中に以下に気づいても「バグ」ではなく既知の課題です（ただし体感を教えてください）。

1. **序盤〜中盤は現金余力がほとんど常にマイナス**です。このため標準AIは新工場建設を
   一度も提案しません（現金安全条件で正しく見送っています）。「準備期に小さく投資する」
   という想定した動きが起きません。ベースライン経済の資金構造の問題として認識しています。
2. **標準AIの投資はturn30以降に偏ります**。VAP需要の伸びは turn18 時点で条件を
   満たしていますが、その時点の現金余力が足りず投資額がゼロになります。
3. **PD省人化の提案はシードによって出たり出なかったりします**（稼働率条件のため）。
4. **PDの絶対価格は終盤も上がり続けます**。圧縮されるのはプレミアム比率だけです。
   これは経済的には正しい挙動ですが、直感には反します。

## 9. 異常を見つけた場合

- 何が・どの会社・どの四半期で起きたか
- 直前の意思決定（投資額・営業人員の増減・販売計画の変更）
- 期待した挙動と実際の挙動の違い
- 可能なら、その時点のExcelエクスポートも保存

# ワークブック構成・レイアウト規約（SAI-3B-2時点）

Excelブック全体のシート構成・配置順・各シート内の書式規約をまとめたもの。

## 1. シート順序（`buildSai3bWorkbook`、`writeWorkbook.ts`）

```
README
経営ダッシュボード          ← SAI-3B-2で追加。§2「近いフロント」の指示によりREADME直後。
売上・数量推移              ← 同上
市場シェア推移              ← 同上
利益・採算推移              ← 同上
資金繰り・財務推移          ← 同上
在庫・運転資金推移          ← 同上
全体サマリー                ← SAI-3B-1のrun単位ダッシュボード（既存）
グラフ                      ← SAI-3B-1の第1版ネイティブグラフ用データ表（既存）
会社別業績
四半期業績
販売分析
調達_生産_在庫
営業能力分析
営業能力_市場別
計画調整分析
Default_信用_警告
ReasonCode集計
80_85_90人比較              ← 複数run（headcount比較）入力時のみ生成
四半期判断トレース
Raw_Case / Raw_Quarter / Raw_Decision / Raw_Adjustment / Raw_Warnings
```

**設計判断**: SAI-3B-2で追加した「経営ダッシュボード」〜「在庫・運転資金推移」の
6シートは、ユーザーが最初に開く可能性が高いシートである（三宅さんの指示§2）。
一方、SAI-3B-1で先に作られた「全体サマリー」「グラフ」は既存ユーザーの参照先
（他ドキュメントや過去のやり取りで既にシート名が言及されている可能性）を
壊さないため、削除・改名はせずそのまま残し、新シート群をその手前に挿入する
という方針を取った（既存シートの位置がズレるだけで、シート自体は変更しない）。

Raw_*シート・四半期判断トレースは「元データへの完全な参照経路」として
末尾に固定し、通常の利用者が最初に目にする範囲から意図的に遠ざけている。

## 2. 個別シート内の書式規約

- 1行目（または注記がある場合は1〜2行目）: ノート（`NOTE_FONT`）。
- ヘッダー行: `writeHeaderRow`（濃紺背景・白文字・太字・折り返し）。
- データ行: `BODY_FONT`（Arial 10pt）。数値列には`numFmt`
  （USD_FORMAT/QUANTITY_FORMAT/RATE_FORMAT/INTEGER_FORMAT）を必ず設定する
  （文字列化された数値をExcel側の計算・グラフから除外させないため）。
- ヘッダー行の直後から`applyFreezeAndFilter`でウィンドウ枠固定＋
  オートフィルターを設定する（`freezeCols`は識別列数、通常2〜6列）。
- 会社別配色を使う小表（ダッシュボード系シート）では、`SUBHEADER_FONT`/
  `SUBHEADER_FILL`（淡い青背景）でKPIブロックの見出しを区切る。

## 3. ダッシュボード系シート（`dashboardCharts.ts`）固有のレイアウトパターン

各KPIブロックは、同一シート内に縦積みで以下の構造を繰り返す
（`writeCompanyQuarterBlock`）:

```
[サブヘッダー] KPIタイトル（run名／営業人数）
[ノート] 単位・データ源・制約の説明
[ヘッダー行] quarter | 会社A | 会社B | ... (中央値のピボット表)
[データ行] × turn数
(空行)
[ヘッダー行] 会社 | 平均 | 最小 | 最大 | 延べdefault seed数 (Layer2統計)
[データ行] × 会社数
(空行×2)
```

対応するネイティブグラフは、同一シートの右側（`chartAnchorCol`、既定8列目）に
アンカーし、ピボット表のセル範囲を直接参照する。run（headcount条件）が
複数ある場合は、runごとにこのブロックが縦に積み重なる。

「経営ダッシュボード」シートのみ特殊で、以下の専用レイアウトを持つ:

```
タイトル + 5秒サマリーの説明ノート
ナビゲーション（他5シートへのハイパーリンク、#'シート名'!A1形式）
[run毎に繰り返し]
  最新四半期スナップショット（サブヘッダー）
  default率/総売上/総営業利益（key-value行）
  会社別の最新値テーブル（売上・粗利益率・営業利益・期末現金・借入合計）
  → 会社別売上のヘッドラインバーチャート
[複数run（headcount比較）入力時のみ]
  80/85/90乖離要約テーブル（会社・seed・最初の乖離turn・KPI・閾値）
```

「市場シェア推移」シートは、市場ごとに独立したピボット表＋グラフを持つ
（全市場・全系列を1枚のグラフに詰め込まない、§7の系列数上限に対応）。

## 4. ネイティブグラフのアンカー配置ルール

- 同一シート内の複数グラフは、`anchorRow`を前のブロックの開始行から
  一定オフセット（例: `headerRowNumber - 3` or `-2` or `-4`）で計算し、
  データ表と視覚的に対応する高さに配置する。
- グラフの列アンカーは、データ表の右側に固定列（`chartAnchorCol`、
  通常8列目）を確保し、データ表の列数がKPIごとに変わっても
  グラフの開始位置がブレないようにする。

## 5. マルチシートのネイティブグラフ注入（chartInjector.ts）

- `xl/charts/`・`xl/drawings/`はワークブック全体で共有される単一の
  フラットディレクトリであるため、`injectNativeChartsMultiSheet`は
  `chart{N}.xml`/`drawing{N}.xml`の番号をブック全体でグローバルに
  ユニークに採番する。
- 各`drawing{N}.xml.rels`内の関係ID（rId）は、そのdrawingファイル
  ローカルスコープのままでよい（他のdrawingのrIdと衝突しない）。
- シート単位の`SheetChartSpecs {sheetName, specs}`の配列を渡す順序が、
  そのままchart番号の採番順になる（`writeWorkbook.ts`の
  `renderSai3bWorkbookToBuffer`では、ダッシュボード系6シート→既存の
  「グラフ」シートの順で番号を振っている）。

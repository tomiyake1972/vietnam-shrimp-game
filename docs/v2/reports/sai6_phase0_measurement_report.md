## 0. 要旨（先に結論）

1. **設計書の推定「遊休人件費は常用人件費の6割」は、条件を分ければ正しかった。**
   SAI-5全機能ONの生存期間で **61.3%**（`decision/labor.ts:15-23` のコメントと一致）。
   全機能OFF（control）の生存期間では **44.2%**。金額は 1社1四半期あたり **$2.03M〜3.20M**。
2. **ただし当初の設計前提「AIは人員を削らない」は誤りだった。** 実測では AI は
   初期6,000人から平均4,266人まで削っている。問題は「削らない」ことではなく
   **「削り方が乱高下していて、削りすぎと持ちすぎを繰り返している」**ことである。
3. **削りすぎの証拠**: 労務制約で作れなかった量が control 生存期間で平均 **2,704 t/四半期**、
   208四半期のうち **131回（63%）** 発生している。単位限界利益 $1,068/t なら **$2.9M/四半期の機会損失**。
4. **係数候補を総コスト（人件費＋解雇費＋採用費＋欠品の機会損失−回避できた欠品）で比較した結果、
   18通りすべてが現行AIより改善した。** 最良は **安全余力15% / 余剰確認期間3Q / 1Q削減上限15%** で
   **総コスト 20.6% 改善**（$989.21M → $785.91M）。**【2026-08-01夜・item 6訂正】この
   15%/3Q/15%は、`replayPolicy`という反実仮想（実際のAI意思決定を置き換えるシミュレーション）
   上で比較した最良の初期候補値であり、Standard AI本体で検証済みの値ではない（引き続き
   「反実仮想上の推奨初期候補」として扱う）。**
5. **最大のボトルネックは労務ではなく原料である。** 原料制約による欠品は 7,259 t/四半期で、
   労務制約（2,704 t/四半期）の **2.7倍**。SAI-6 の能力調整だけでは default 率の改善に限界がある。
6. **【2026-08-01訂正】借入余力の超過は生存期間中も一定数発生する**（control生存期間で
   20/208＝9.6%、allOn生存期間で4/108＝3.7%。旧報告の「0/208」は符号バグによる誤りで
   撤回する）。ただし発生率自体は低く、Phase 1A-2の因果接続監査で判明したとおり
   **20破綻ケース中19ケースで「銀行の承認額＝借入余力上限」が常に成立**しており、
   与信上限そのものが支配的な制約である。借入判断（希望額の算定式）の是正だけで
   解決できる範囲は限定的であることが、Phase 1AのA/B実測（効果ほぼゼロ）でも裏付けられている。
   **【2026-08-01夜・再検証中（item 6訂正）】** ただし上記「与信上限そのものが支配的な
   制約」は破綻前後20ケース（80四半期）という狭い母集団についての判定であり、
   `scripts/sai6Phase1A2CashConstraintDecomposition.ts`による生存期間全体（control、
   208四半期中179四半期が調達時資金制約、そのうち193四半期がscaleRatio<1）の分解では
   与信上限だけで説明できるケースは0件、大半（90.2%）は入出金タイミング差（前期末現金の
   60%のみを見て当期の確実な売掛金回収を見ない設計）で説明される。したがって
   「与信上限が支配的制約」という一般化は**再検証中**であり、`sai6_phase1a2_completion_report_corrected_2026-08-01.md`
   の作業1を参照。

### 1.5 二重計上の検証（ご指示7・設計補正B の根拠）

> **商品別余剰の単純合計が共通前処理の余剰を上回った標本の割合 = 100.0%（全標本）**
> **超過分の平均 = 1,710 t/四半期**

理由は構造的である。標準初期条件の名目能力は
HOSO 10,000 ＋ PD 8,000 ＋ VAP 6,000 = **24,000 t** に対し、
共通前処理は **22,000 t** しかない（`standardBaseline.ts:68-71`）。
つまり **商品別ラインの合計は共通工程を 2,000t 上回っており、
商品別余剰を単純合計すると必ず共通工程のボトルネック分を二重に数える**。

さらに労務余剰（12,167 t）は**全商品で共有される第3の軸**であり、
商品別余剰とも共通工程余剰とも独立に足してはいけない。

**この3つを合算してはならないことが実測で確認できた。** 設計補正Bへ反映する。

設計補正Aの記述をこの実測に合わせて修正する（§3-A）。

## 2. 係数候補の比較

### 2.1 評価方法と、その限界（正直な明記）

実績軌跡（各四半期に実際へ配属された人員 = `productiveRegularLaborCost ÷ 給与`）を
所与として、候補方針を当てはめる**反実仮想リプレイ**である。

比較は**総コスト**で行う。現行AI（実績軌跡）にも同じ一時費用を課して公平にした。

```
方針の総コスト   = 人件費 + 解雇費 + 採用費 + 欠品の機会損失 − 回避できた欠品の価値
現行AIの総コスト = 実績の人件費 + 実績の人員変動に課した解雇費・採用費
改善額           = 現行AIの総コスト − 方針の総コスト
```

「回避できた欠品の価値」は、方針が現行AIより多く人員を持っていた四半期について
`min(実測の労務制約欠品トン, 追加人員 × 効率) × 単位限界利益` とした
（**実測の欠品量を上限にしており、過大評価はしていない**）。

**限界**: 人員を削れば生産・成約・価格も変わるが、リプレイはそれを追えない。
方針の**相対比較**には使えるが、絶対額の予測には使えない。
最終判断は Phase 1 の全再シミュレーションで行う必要がある。

### 2.2 現行AIの基準値（control 生存期間、20会社ケース）

| 項目 | 値 |
|---|---:|
| 人件費 | $887.29M |
| 解雇費（実績の人員減に課した場合） | $101.92M |
| 採用費 | $0.00M |
| **総コスト** | **$989.21M** |
| **人員変動の総量** | **50,961人**（増減の絶対値合計） |

**現行AIは人員を乱高下させている。** 20ケース×平均10.4四半期＝208四半期で
50,961人の変動は、1四半期あたり平均245人。解雇コストを導入すると
これだけで人件費の **11.5%** に相当する費用が発生する。

### 2.3 候補グリッド（採用リードタイム 1Q）

### 2.4 読み取れること

1. **18通りすべてが現行AIより改善した**（+$64M 〜 +$203M、6.5% 〜 20.6%）。
   現行AIの乱高下（人員変動 50,961人）が、どの方針よりも高くつく。
2. **余剰確認期間は 3Q が 2Q より一貫して良い**（同じ他条件で +$60M 〜 +$96M）。
   急いで削ると欠品回避の価値を失う。
3. **1Q削減上限は 15% が最良**。10% は削減が遅すぎて人件費が $1,086M と最も高く、
   20% は削りすぎて欠品回避の価値（$326M → $253M）を失う。
4. **安全余力の影響は小さい**（10/15/20% で最大 $2.5M の差）。
   ただし **15% 以上で「不足人月 = 0」を達成する**（3Q・15%上限の条件下）。
   10% では 2Q・15%上限の組で不足 1,003人月が発生する。
5. **人員変動は 3Q・10%上限で最小**（31,641人、現行の 62%）だが、
   人件費が最も高くなるため総コストでは劣る。

### 2.6 削減の回収期間（ご指示6）

| 項目 | 値 |
|---|---:|
| 1人削減の節約 | $1,000 / 四半期 |
| 1人削減の一時費用（解雇2Q分） | $2,000 |
| **単純な回収期間** | **2.0 四半期** |
| 削減して再採用した場合の一時費用（解雇2Q＋採用1Q） | $3,000 |
| **往復が損にならない最低期間** | **N ≥ 3 四半期** |

**この 3四半期が、余剰確認期間の下限を経済的に規定する。**
「3四半期以上続く余剰でなければ削っても損」という関係が、
実測で最良だった**確認期間 3Q** と整合する。偶然の一致ではなく、
`(解雇費 + 採用費) ÷ 四半期給与 = 3` という関係から導かれる。

## 4. 計測から見えた設計上の追加論点

### 4.1 原料制約が最大のボトルネック（SAI-6 の効果に対する事前の但し書き）

原料制約による欠品 7,259 t/Q は労務制約 2,704 t/Q の **2.7倍**である。
SAI-6 が労務・設備の能力調整と価格戦略に集中する以上、
**default 率の改善幅には構造的な上限がある**ことを、受入判定の前に共有しておきたい。

原料が不足する理由は調達の資金制約（`PROCUREMENT_CASH_CONSTRAINED` が
allOn 32Q で 566回発火、SAI-5 の A/B 比較より）と考えられる。
これは設計補正A（二段階財務）が直接効きうる領域であり、
**SAI-6 の中で最も default 率に効くのは、能力調整でも価格でもなく資金計画の可能性がある**。

### 4.2 設備制約は実質的に効いていない（Phase 2 除外の妥当性）

設備制約による欠品は 83 t/Q（労務の 3%）。設備能力は余っており、
休止しても増設しても生産は変わらない。
**Phase 2（設備休止）を SAI-6 から外すというご判断は、実測に照らして妥当である。**

ただし §1.5 のとおり、商品別ラインの合計（24,000t）が共通前処理（22,000t）を
2,000t 上回っている構造は残る。将来ライン単位の休止を検討する際は、
「どのラインを止めても共通工程が先に律速する」ことを踏まえる必要がある。

### 4.3 32Q では control でも全滅する

SAI-5 の A/B 比較（8Q）では control の default 率 42.5% だったが、
32Q では 20/20 ケースが破綻する。生存期間は control 平均 10.4Q、allOn 平均 5.4Q。

**SAI-6 の受入試験は 8Q と 32Q の両方で行う必要がある。**
8Q だけでは長期の能力調整の効果が測れず、32Q だけでは破綻後のノイズに埋もれる。

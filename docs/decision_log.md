# 意思決定ログ（仕様変更記録）

このファイルは、ゲーム仕様に関する今後の変更を記録するためのテンプレートです。仕様変更を行う・提案する際は、下記フォーマットに沿って新しいエントリをこのファイルの末尾に追記してください。

## 記入ルール

- 見出しは `## YYYY-MM-DD：変更テーマ` の形式（日付は変更を決定・記録した日）
- 各セクションは空でも省略せず、「なし」「TODO」等を明記する
- 「決定事項」は確定した仕様のみを記載し、検討中の案は「未解決事項」に記載する
- このログで確定した仕様変更は、対応する`docs/`配下のファイル（`game_manual.md`, `parameter_spec.md`等）にも反映すること。反映していない場合は「影響する仕様書」欄にその旨を明記する

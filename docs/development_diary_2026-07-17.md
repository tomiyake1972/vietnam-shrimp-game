## 1. 本日の到達点

本日はV1（本番稼働中のゲーム）の会社画面（`CompanyDashboard.tsx`）に絞り、表示の正確性を3段階で是正した。V2の新規実装は行っていない。

## 2. 外部調達量プレースホルダーの動的化（`ea46b26`）

会社画面の外部調達量入力欄が、実際のゲームロジックと無関係な固定表示「0〜3000 t」になっていたバグを修正した。`company.processingCapacity - farmingInput`（加工能力から自社養殖投入量を引いた値）を実質上限として表示するよう変更し、表示上の上限と実際に受け付けられる上限の乖離をなくした。

## 3. 前期損益計算書の正式な表示への拡張（`24a8eb7`）

それまで「売上」「純利益」の2行だけだった前期PL表示を、正式な損益計算書の形式へ拡張した。

```
売上高 → 売上原価 → 売上総利益 → 加工費・管理費 → 営業利益 → 支払利息 → 経常利益
```

の構造で表示し、調整メモ（adjustmentノート）も併せて表示するようにした。

## 4. 売上原価の会計構造の是正（`0a2bcf8`）

同日のうちに、3.で拡張した表示自体に会計上の誤りがあることに気づき、同日中に修正した。加工費は製造原価であり売上原価の一部であるにもかかわらず、これを販管費側に計上していた。原料費（cogs）と加工費を合算して売上原価とし、固定費（overhead）のみを販売費及び一般管理費として計上する形に是正した。

```
売上高 → 売上原価（原料費＋加工費） → 売上総利益 → 販管費 → 営業利益 → 支払利息 → 経常利益
```

この3コミットは、いずれも `app/components/CompanyDashboard.tsx` 1ファイルへの小規模な変更であり、表示ロジックの是正にとどまる。ゲームエンジン（`gameEngine.ts`）側の計算ロジックには手を加えていない。

## 第1部　ゲームの全体像

### 1.1 あなたは何者か

あなたはベトナムのエビ加工・輸出企業の経営者である。養殖農家から原料エビを買い付け、自社工場で加工し、中国・米国・EU・日本・その他の市場へ輸出する。同じ市場には他に4社の競合がいて、原料の買い付けでも製品の販売でも直接競合する。

ゲームは**四半期（Quarter）を1ターン**として進む。標準シナリオは8年32ターン。現在稼働中の `Test12` は2015年Q1から始まっている。

### 1.2 5つの会社

会社にはそれぞれ異なる強みがある。プレイヤーは1社を選び、残りは自動方針で動く。

| 会社ID | 表示名 | 性格 | 得意なこと |
|---|---|---|---|
| **BAL** | バランス型水産 | balanced | 3商品をバランスよく作れる。突出した強みは無いが弱点も無い |
| **MASS** | 大量生産・価格競争水産 | massMarket | HOSO加工能力3万トンと圧倒的。人員も9,000人。薄利多売型 |
| **JPQ** | 日本・品質志向水産 | japanQuality | PD技能0.95。日本市場向けの高品質PD |
| **VAP** | VAP特化水産 | vapSpecialist | VAP能力12,000トン・技能0.95。最も付加価値の高い商品に特化 |
| **CONSV** | 保守的・財務慎重水産 | conservative | 規模は最小だが出勤率0.97と最も高い。財務的に慎重 |

規模の違いは大きい。共通前処理能力で見ると MASS 36,000トン に対し CONSV 15,000トン と2.4倍の差がある。ただし規模が大きいことは有利とは限らない。`Test12` の Turn 2 では最大手の MASS が **粗利率 −86.3%、当期純利益 −$13,354,591** という大赤字を出している。

### 1.3 3つの商品

| 商品 | 正式名 | 内容 | 価格帯（2015Q2 日本向け） |
|---|---|---|---|
| **HOSO** | Head-On Shell-On | 有頭・殻付き。加工度が最も低い | $4.15/kg |
| **PD** | Peeled & Deveined | 頭・殻・背ワタを除去したむき身 | $4.99/kg |
| **VAP** | Value Added Product | 衣付け・味付け・調理済みなどの付加価値加工品 | $6.92/kg |

**数量はすべて HOSO換算トン（HOSO-equivalent tons）で表す。** これは「元の有頭殻付きエビ何トン分か」という単位である。PD 1トンを作るのに物理的には HOSO 約1.85トンが必要だが、ゲーム内では「HOSO換算1トンの原料から HOSO換算1トンの PD ができる」と扱う。単位の定義に歩留まりが織り込まれているためで、この点を誤解すると計算が二重に減ってしまう。

限界利益（1トンあたりの粗利貢献）のランキングは次のとおり。

```
JP vap $2,896 > EU vap $2,750 > US vap $2,480 > OTHER vap $2,130 > CN vap $2,112
> JP pd $1,417 > EU pd $1,377 > US pd $1,289 > CN pd $1,194 > OTHER pd $1,182
> JP hoso $829 > EU hoso $809 > US hoso $768 > CN hoso $727 > OTHER hoso $706
```

**VAP は PD の約2倍、HOSO の約3倍**。市場別では常に 日本 > EU > 米国 > その他 > 中国 の順。したがって理論上は「日本向けVAPを最大限作る」のが最適に見えるが、実際にはそれを妨げる制約が何重にもある。それがこのゲームの本体である。

### 1.4 5つの市場

| 市場ID | 名称 | 規模の目安（2015Q2 HOSO需要） |
|---|---|---|
| CN | 中国 | 42,848 t |
| US | 米国 | 35,967 t |
| EU | 欧州 | 29,176 t |
| OTHER | その他 | 16,892 t |
| JP | 日本 | 10,086 t |

日本市場は**単価が最も高いが規模が最も小さい**。VAP に限れば日本の需要は 2,012.81t しかなく、1社が取れるのはその 35%、つまり **704.49t が上限**である。ここが本ゲームで最も重要な罠のひとつになっている。

## 第2部　1ターンの流れ

### 2.1 意思決定の6分野

毎四半期、次の6分野について意思決定する。

1. **販売計画** — どの市場のどの商品を、何トン、いくらで、営業何人で売るか
2. **調達計画** — 国内でいくらの価格で何トン買うか、輸入するか、自社養殖をどれだけ放養するか
3. **生産計画** — どの商品を何トン作るか、優先順位はどうするか
4. **人員配置** — 正社員を何人配置するか、臨時工・残業をどうするか、技能・出勤率をどうするか
5. **財務** — 借入を申請するか、返済するか
6. **設備投資** — 新規案件を提案するか

これらを提出して四半期を確定すると、エンジンが5社分をまとめて処理し、結果が確定履歴として保存される。

### 2.2 エンジンの処理順序

確定処理はおおむね次の順で進む。

```
① 市場価格形成       世界HOSO価格・PD/VAPプレミアム・ベトナム国内原料価格を決定
② 原料調達           国内買付の配分、輸入発注、養殖の放養
③ 原料入庫           前期の輸入到着・養殖収穫を在庫へ計上
④ 生産               5段階の能力制約を順に適用して生産量を決定
⑤ 品質               操業リスクから不適合率・品質スコア・事故を判定
⑥ 販売               成約競争力から市場×商品ごとの成約を配分
⑦ 履行               既存の約定残と当期成約を、生産できた製品で充当
⑧ 決算               P/L・B/S・C/F を確定
⑨ 財務               信用スコア・借入余力・財務制限条項を判定
⑩ 設備投資           案件の進捗・完成・固定資産振替
```

重要なのは、**販売の成約は生産の後に決まる**が、**約定（契約）の履行は成約の翌四半期**であることだ。今期成約した契約は来期納品する。したがって「今期作ったもの」は「前期に成約した契約」を埋めるために使われる。この1ターンのラグが資金繰りと在庫計画を難しくしている。

## 第3部　販売のしくみ

### 3.1 何を決めるのか

市場（5つ）×商品（3つ）= **15の組み合わせ**それぞれについて、次を決める。

- 販売希望量（トン）
- 提示価格の調整額（基準価格からの±$/kg）
- 割り当てる営業人員数

営業人員には**総数の上限**がある。BAL なら 18人。この上限は増やせない。**再配分しかできない。** これがゲームの中核的な制約である。

### 3.2 営業人員が決めるもの

営業人員は2つの効果を持つ。

**カバレッジ（市場への到達度）**:
```
coverageScore(h) = 0.15 + 0.85 × h / (h + 6)
```

| 人数 | カバレッジ |
|---|---|
| 0 | 0.150 |
| 1 | 0.271 |
| 2 | 0.363 |
| 3 | 0.433 |
| 4 | 0.490 |
| 6 | 0.575 |
| 10 | 0.681 |

**成約処理能力（HOSO換算トン）**:
```
processingCapacity(h) = 200 + 4800 × h / (h + 10)
```

| 人数 | 成約能力(t) |
|---|---|
| 0 | 200.00 |
| 1 | 636.36 |
| 2 | 1,000.00 |
| 3 | 1,307.69 |
| 4 | 1,571.43 |
| 6 | 2,000.00 |
| 10 | 2,600.00 |

**0人でも200トンは成約する。** これは「既存顧客による最低限の成約力」という設計である。この性質は極めて重要で、**利益率の低い市場×商品には人を置かず、それでも200トンずつ拾う**という戦略が成立する。BAL の Turn 3 推奨案では、HOSO の5市場すべてに0人を割り当て、合計1,000トンを無人で確保している。

どちらの曲線も**逓減する**。人数を増やすほど1人あたりの効果は薄くなる。6人を1つの市場に集中させるより、2人ずつ3市場に分けたほうが合計は大きい（2,000 vs 3,000）。

### 3.3 4つの上限

1社が1つの市場×商品で成約できる量は、次の**最小値**に制限される。

```
min( ① 販売希望量,
     ② processingCapacity(営業人員数),
     ③ 対象需要 × 0.35,
     ④ 承認済み配分上限 )
```

③ の **35%上限（`maximumSupplierShare`）** が曲者である。1社が市場を独占できないようにする仕組みだが、小さな市場では営業人員の能力より先にこちらが効いてしまう。

**実例（BAL Turn 2 の日本向けVAP）**: 営業4人を割り当てたので成約能力は 1,571.43t。しかし日本のVAP需要は 2,012.81t しかなく、その35%は **704.49t**。結果として 704.49t しか成約できず、**約867トン分の営業能力が無駄になった**。この4人を他市場へ回していれば、その分だけ成約が増えていた。

15の組み合わせそれぞれの35%上限（2015Q2時点）は次のとおり。

| | CN | US | EU | JP | OTHER |
|---|---|---|---|---|---|
| HOSO | 14,996.81 | 12,588.43 | 10,211.66 | 3,530.25 | 5,912.21 |
| PD | 6,982.99 | 5,861.57 | 4,754.88 | 1,643.80 | 2,752.91 |
| VAP | 2,992.71 | 2,512.10 | 2,037.80 | **704.49** | 1,179.82 |

日本向けVAPの 704.49t が突出して小さい。ここに人を集中させてはいけない。

### 3.4 価格をどう決めるか

提示価格は基準価格からの差で指定する。競争力への影響は指数関数。

```
priceScore = exp( -3.0 × (提示価格 - 基準価格) / 基準価格 )
```

結果は [0.5, 1.6] にクランプされる。目安として:

| 基準価格からの乖離 | priceScore |
|---|---|
| +10%（値上げ） | 0.741 |
| +5% | 0.861 |
| 0% | 1.000 |
| −5% | 1.162 |
| −10%（値下げ） | 1.350 |
| −15% | 1.568 |
| −15.7%以上 | 1.600（上限に到達） |

**約15.7%を超える値下げは無意味である**（`ln(1.6) / 3.0 ≒ 0.157`。上限 1.6 に張り付くため）。逆に言えば、値下げが効くのは 15%程度までで、それ以上は単に利益を捨てるだけになる。

入力バリデーションとして、基準価格の 0.5倍未満または 2.0倍超は異常値としてエラーになる。

### 3.5 成約競争力の合成

最終的な競争力は5要素の加重平均。

| 要素 | ウェイト |
|---|---|
| 価格 | 0.35 |
| カバレッジ | 0.25 |
| 顧客関係 | 0.15 |
| 品質 | 0.15 |
| 納期信頼性 | 0.10 |

5社の他に「外部選択肢」（他産地の供給者・買わないという選択）が競争力 0.35 で参加する。5社の競争力がすべて低ければ、需要は外部へ流れる。

配分は **water-fill 方式**で、競争力に比例して按分する。**入力の順序には一切依存しない。**

顧客関係・品質・納期信頼性が未接続の場合は中立値 50 が使われる。

### 3.6 約定残（契約残高）

成約した契約は**翌四半期が納期**（`standardLeadTimeTurns = 1`）。納期に製品が用意できなければ約定残として繰り越され、納期遅延は納期信頼性スコアを下げる。

BAL は Turn 2 で 12,372.5t を履行したが新規成約は 7,127.56t にとどまり、2015Q3納期の約定残が **5,981.16t（$32,399,294.97）** 残っている。これを Turn 3 で履行できるかが当面の最大の課題である。

## 第4部　原料調達のしくみ

原料の入手経路は3つある。**国内買付**、**輸入**、**自社養殖**。それぞれリードタイムと原価が違う。

### 4.1 国内買付（当期入手・当期現金払い）

ベトナム国内の養殖農家から買い付ける。**当期に入庫し、当期に現金で支払う**（`apDomesticPaymentQuarters = 0`）。

提示買付価格を市場価格に対する差で指定する。競争力は販売の逆符号。

```
priceScore = exp( +3.0 × (提示価格 - 市場価格) / 市場価格 )
```

高値を提示するほど有利になる。クランプは [0.5, 1.6]。

買付競争力のウェイト:

| 要素 | ウェイト |
|---|---|
| 価格 | 0.40 |
| カバレッジ | 0.25 |
| 農家との関係 | 0.20 |
| 支払信頼性 | 0.15 |

調達人員のカバレッジ曲線は販売と同形（`0.15 + 0.85·h/(h+6)`）。

**調達処理能力は工場能力に連動する**（Phase 6.3 以降）。

```
調達能力 = 工場共通原料処理能力 × ( 0.5 + 1.2 × 人員 / (人員 + 10) )
```

人員8〜20人で工場共通能力の約 1.03〜1.30倍になる。つまり**通常操業では制約にならないが、急激な買い占めをしようとすると効いてくる**。以前は company-lab 専用に約100倍の一律補正が入っており、制約として一度も機能していなかった。これは Phase 6.3 で廃止された。

買付シェアにも 35%上限（`maximumBuyerShare`）がある。さらに「実際には買えない量を過大申告して国内価格だけを吊り上げる」抜け道を防ぐため、**価格形成へ影響を与えられるシェアも別途 35%に制限**されている（`maximumPriceInfluenceShare`）。

**実例（BAL Turn 2）**: 市場価格 $2.4760 に対し $2.5260（+$0.05）を提示。カバレッジ 0.71667、競争力 0.61978 で、希望量 6,000t を全量確保。利用可能供給 31,176.61t に対して未配分ゼロ。

### 4.2 輸入（2四半期後に到着）

エクアドル・インド・インドネシア・ベトナムから輸入する。**リードタイムは2ターン**。発注した四半期から数えて2四半期後に到着する。到着するまでロットのステータスは `inTransitImport` であり、**生産には使えない**。

支払は翌四半期（`apImportPaymentQuarters = 1`）。

着地原価:
```
着地価格 = 起点FOB価格 × (1 + 関税0.05) + 運賃$0.15/kg + 保険諸掛$0.05/kg + 原産国調整
```
原産国調整は現在すべて 0。

各原産国から輸入できる量は、その国の輸出可能供給量の **10%** が上限。

### 4.3 自社養殖（1四半期後に収穫）

自社の養殖池に稚エビを放養する。**収穫は翌四半期**。それまでステータスは `growingAquaculture` で生産に使えない。

放養量は養殖能力の範囲内（BAL なら 15,000t）。2つのレバーがある。

- **養殖強度（intensity, 0〜1）** — 高めると生産量が最大 +50% 増えるが、疾病脆弱性も最大 +80% 増える
- **バイオセキュリティ（bioSecurityLevel, 0〜1）** — 疾病影響を最大 70% 緩和する

生残率の下限は 0.10（壊滅的な疾病でも全滅はしない）。

単位取得原価は **$3.2/HOSO換算kg の固定値**。これは会計処理を簡略化するための暫定的な扱いである。国内買付が $2.5前後で買えていることを考えると、養殖は現状**割高**である。

**実例（BAL Turn 2）**: 放養 6,666.67t（能力15,000、intensity 0.6、biosecurity 0.8）→ 翌期に 8,666.67t を収穫予定。単価 $3.2。

### 4.4 ロットのステータスを必ず確認すること

原料在庫は**ロット単位**で管理され、それぞれにステータスがある。

| ステータス | 意味 | 生産に使えるか |
|---|---|---|
| `available` | 入庫済み | **使える** |
| `growingAquaculture` | 養殖中 | 使えない |
| `inTransitImport` | 輸送中 | 使えない |

**これは非常に間違えやすい。** BAL の Turn 2 期末の原料在庫は合計 13,316.67t あるが、内訳は次のとおり。

| ロット | 数量(t) | 単価 | ステータス | Q3に使えるか |
|---|---|---|---|---|
| `RM-aquaculture-2015Q2-VN-BAL-1` | 8,666.67 | $3.20 | `growingAquaculture` | ✗ |
| `RM-import-2015Q1-ID-BAL-1` | 3,000.00 | $4.778 | `inTransitImport` | ✗ |
| `RM-domestic-2015Q2-VN-BAL-1` | 1,650.00 | $2.526 | `available` | **✓** |

**Q3 に実際に使えるのは 1,650トンだけである。** 「13,316トンある」と考えて生産計画を立てると破綻する。

原料ロットに**使用期限は設定されていない**（`defaultShelfLifeTurns: undefined`）。ただし品質エンジンは原料の経過期間をリスク要因として見ており、実務的な鮮度限界を 4四半期として扱っている。

## 第5部　生産のしくみ

### 5.1 5段階の制約を順に通す

生産計画は次の順で制約される。**順序が重要である。**

```
① 原料在庫（available のロットのみ）
② 工場共通処理能力
   ↓ ここで歩留まり（saleableRecoveryRatio）を一度だけ適用
③ 冷凍・包装能力
④ 商品別設備能力
⑤ 有効労働能力
```

**③ 冷凍・包装能力が ④ 商品別能力より先に来る**点に注意。冷凍・包装は全商品が共有する能力なので、ここで削られると商品別能力に余裕があっても作れない。

各段階で削られた場合、その理由が「制約要因」として結果に記録される。意思決定画面ではこれが表示されるので、**どこがボトルネックになっているかを必ず確認する。**

### 5.2 実効能力は公称の85.5%

工場の能力表に書かれているのは**公称能力**である。実際に使えるのは:

```
実効能力 = 公称能力 × 0.90（基準稼働率） × 0.95（設備可用率） = 公称 × 0.855
```

補正はこの2つだけで、1工場の5つの能力プール（共通処理・HOSO・PD・VAP・冷凍包装）すべてに一律で掛かる。

BAL の場合:

| 能力プール | 公称(t) | 実効(t) |
|---|---|---|
| 共通前処理 | 22,000 | 18,810 |
| HOSO | 10,000 | 8,550 |
| PD | 8,000 | 6,840 |
| VAP | 6,000 | 5,130 |
| 冷凍・包装 | 20,000 | 17,100 |

工場が `active` でなければすべて 0 になる。

### 5.3 優先順位の効果

3商品に優先順位をつける。**数字が小さいほど優先度が高い。** 同順位なら比例配分（water-fill）で解決し、入力順には依存しない。

優先順位が効くのは**能力が不足しているときだけ**である。総生産量が能力の内側に収まっていれば、順位を変えても結果は変わらない。

検証例（BAL）:

- 総希望量 3,000t のとき → 優先順位を変えても**何も変わらない**
- 総希望量 19,000t のとき → VAP を1位にすると PD から VAP へ 1,900t 移る。ただし**両方とも合計は 17,100t で頭打ち**（冷凍・包装能力で凍結される）

つまり優先順位は「限られたパイをどう切るか」の指定であって、パイを大きくするものではない。

**注意**: かつて「VAPの処理可能量は約810t」と説明したことがあるが、これは VAP が優先順位3位の場合の条件付きの値である。優先順位を変えれば変わる。固定値ではない。

### 5.4 労働能力

1人あたりの処理能力:

```
1人あたり能力(t) = 6（基準効率） × 出勤率 × 技能レベル
```

BAL（出勤率0.95、技能 HOSO 0.85 / PD 0.80 / VAP 0.75）:

| 商品 | 1人あたり(t) |
|---|---|
| HOSO | 4.845 |
| PD | 4.560 |
| VAP | 4.275 |

臨時工は基準効率 3.5（正社員の約58%）。残業は所定の 30% まで、ただし効率は 50%（残業1時間分の能力は通常0.5時間分）。残業には 1.5倍の割増賃金がかかる。

### 5.5 遊休人件費という落とし穴

**これは本ゲームで最も損をしやすいポイントである。**

```
生産的な正社員数 = min( 各工程に配置した合計人数, 提出した正社員総数 )
遊休正社員数     = max( 0, 提出した正社員総数 - 生産的な正社員数 )
遊休人件費       = 遊休正社員数 × $1,000
```

つまり**配置しなかった正社員の給与は、丸ごと損失として計上される。**

正社員数は毎四半期自由に増減でき、**解雇費用も採用費用もかからない**（現在の実装ではモデル化されていない）。したがって「必要な人数だけ配置する」のが常に正解になる。

**実例（BAL Turn 2）**: 6,000人を提出したが、生産に必要だったのは 2,719人分。差の 3,281人分、**$3,280,530 が遊休人件費として売上原価に計上された。** これは売上総利益 $15,076,474 の 21.8% に相当する。

**Turn 3 の試算**:

| 配置人数 | 営業利益 | 当期純利益 |
|---|---|---|
| 6,000人 | −$0.12M | **−$1,287,705**（赤字） |
| 1,400人 | +$4.48M | **+$2,484,221**（黒字） |

人員配置を変えるだけで **$377万** の差が出る。他の何も変えていない。

必要最低人数の計算方法: 商品ごとに「生産量 ÷ 1人あたり能力」を足す。BAL の Turn 3 案（HOSO 1,130t / PD 2,606t / VAP 2,246t）なら:

```
HOSO: 1,130 / 4.845 = 233.2人
PD  : 2,606 / 4.560 = 571.4人
VAP : 2,246 / 4.275 = 525.3人
合計 1,330人
```

1,300人だと VAP に 127.91t の不足が出て、制約要因が「有効労働能力」になる。余裕を見て 1,400人が推奨値である。

## 第6部　品質のしくみ

### 6.1 操業リスクがすべての起点

品質は「操業リスク（operationalRisk）」という 0〜1 の合成指標から決まる。

```
operationalRisk = 0.35 × 設備稼働ストレス
                + 0.20 × 残業ストレス
                + 0.15 × 臨時工比率
                + 0.10 × 生産の複雑度
                + 0.10 × 原料経過期間
                + 0.10 × 生産立上ストレス
```

設備稼働ストレスは:
```
clamp( (稼働率 - 0.80) / 0.20, 0, 1 ) ^ 2
```
稼働率80%までは 0、100%で 1 になる二次関数。

### 6.2 リスクが何を引き起こすか

**不適合率**:
```
不適合率 = 0.08 × operationalRisk ^ 1.5
```

不適合品の内訳は 格下げ45% / 手直し25% / 廃棄30%。

**歩留まりの低下**:
```
saleableRecoveryRatio = clamp( 1 - 廃棄率, 0.90, 1 )
```
最悪でも 90% は残る（バッチ単位で最大10%までの損失）。

**品質スコア**:
```
observedQualityScore = 85 - 30 × operationalRisk - 重大事故減点
```

品質スコアは即座に置き換わるのではなく、平滑化して更新される。**悪化は速く（α=0.20）、回復は遅い（α=0.08）。** 一度落とした品質を取り戻すには、悪化させた期間の 2.5倍の期間がかかる計算になる。

納期信頼性も同様（悪化 α=0.25 / 回復 α=0.08）。顧客信頼はさらに慎重で（悪化 α=0.18 / 回復 α=0.06）、品質と納期の 50:50 で決まる。

**格下げ品は 25% 引きで売られる**（`downgradePriceDiscountRatio = 0.25`）。

### 6.3 重大事故

低確率で重大事故が起きる。

```
事故確率 = 0.002（基礎） + 0.08 × operationalRisk ^ 2   （上限 0.10）
```

operationalRisk が 0 なら 0.2%、1.0 なら 8.2% となる。発生すると重大度（0〜1の乱数）に応じて追加廃棄、品質減点（最大40点）、信頼減点（最大25点）が課される。

`Test12` の Turn 2 では JPQ が1件の重大事故を起こしている。

### 6.4 現在の実装上の癖（重要）

**現行バージョンでは、人員を削減しても品質は悪化しない。**

理由は `laborUtilizationRate` の定義にある。これは「生産量 ÷ 配分した労働能力」なので、必要なだけ配置すれば構造的にほぼ 1.0 になる。その結果、設備稼働ストレスは常に 1.0 に張り付き、人員の増減で動かない。

また `productionRampStress` は生産量が減少する局面では 0 になる。

したがって「人員を絞って遊休費を削る」戦略に品質面のペナルティはほとんど無い。これは意図した設計ではなく、指標定義の副作用である。将来のバランス調整で変わる可能性がある。

**実例（BAL Turn 2）**: 3商品すべて同一の値になった。設備稼働ストレス 1、残業 0、臨時工 0、複雑度 1、原料経過 0.1625、立上 1 → operationalRisk 0.56625。不適合率 3.41%、廃棄 1.02%、歩留まり 98.98%、品質スコア 68.01。累積の期末スコアは 79.15 で、これは5社中最低だった。

## 第7部　財務のしくみ

### 7.1 損益計算書の構造

```
総売上
− 品質起因の売上控除（格下げによる値引き）
= 純売上

− 売上原価
    原料費
    加工費
    労務費
    工場固定費
    手直し費
    廃棄損
    遊休人件費        ← 忘れやすい
    未吸収固定費
    設備投資保守費
= 売上総利益

− 販管費
= 営業利益
− 支払利息
= 税引前利益
− 法人税（20%）
= 当期純利益
```

**販管費の内訳**:
```
8,000 × 営業人員数 + 7,000 × 調達人員数 + 800,000（管理固定費） + 100 × 販売トン数
```

管理固定費 $800,000 は毎期必ず発生する。売上ゼロでもかかる。

**工場固定費**は $1,200,000/四半期 + 用役固定費 $250,000/四半期 + 用役変動費 $25/トン。

### 7.2 運転資本と資金繰り

```
売掛金の回収    : 翌四半期（arCollectionQuarters = 1）
輸入買掛の支払  : 翌四半期（apImportPaymentQuarters = 1）
国内買付の支払  : 当期現金（apDomesticPaymentQuarters = 0）
```

**この非対称性が資金繰りを厳しくする最大の要因である。** 原料は今払い、売上は来期入金。成長するほど現金が減る。

**実例（BAL Turn 2）**: 当期純利益は +$9,315,379 の黒字だが、営業キャッシュフローは **−$56,455,122**。現金は $89,546,223 から **$31,591,101** へ、1四半期で 65% 減少した。

内訳を見ると、売上債権の増加が $52,309,748、買掛金の減少が $14,334,000。黒字倒産の教科書的な形である。

### 7.3 信用スコアと借入

信用スコアは9つの要素の加重平均。

| 要素 | ウェイト |
|---|---|
| 現金余裕月数 | 0.15 |
| 営業キャッシュフロー | 0.15 |
| 収益性 | 0.15 |
| レバレッジ | 0.15 |
| 支払実績 | 0.10 |
| インタレストカバレッジ | 0.10 |
| 自己資本比率 | 0.10 |
| 延滞履歴 | 0.05 |
| 顧客信頼・納期 | 0.05 |

格付けの閾値: **A ≥ 80 / B ≥ 65 / C ≥ 50 / D ≥ 35 / E < 35**。初期値は 65（B）。

金利:
```
適用金利 = 基準金利4%（年） + 格付けスプレッド + 各種サーチャージ
```

| 格付け | スプレッド（年） |
|---|---|
| A | +2.0% |
| B | +3.5% |
| C | +5.0% |
| D | +7.0% |
| E | +9.0% |

サーチャージ: 緊急融資 +10%、条項違反 +1.5%、延滞履歴 +2.0%、借換 +0.5%、長期借入 +0.5%。

**借入余力**は担保ベースと利益ベースと格付けベースの3つのうち最も厳しいものになる。担保の掛け目:

| 担保 | 掛け目 |
|---|---|
| 売掛金 | 0.70 |
| 原料在庫 | 0.40 |
| 輸送中原料 | 0.15 |
| 製品在庫 | 0.30 |

**実例（BAL Turn 2）**: 信用スコア 73.25（Tier B）。担保価値 $14,395,173.77、利益ベース $0、格付けベース $157,834,145.69。最も厳しい担保ベースが効いて総枠 $14,395,173.77。既存借入が $52,540,000 あるため、**追加借入余力は $0**。拘束要因は `collateralBased`。

つまり BAL は現時点で**追加の借入ができない**。手元現金 $31.6M で Turn 3 を回さなければならない。

### 7.4 財務制限条項（コベナンツ）

| 条項 | 基準 |
|---|---|
| 自己資本比率 | 15% 以上 |
| 負債比率 | 85% 以下 |
| インタレストカバレッジ | 1.0 以上 |
| 返済延滞なし（`noArrears`） | 延滞が1件でもあれば違反（閾値パラメータを持たない） |

違反すると信用スコアが 8点減点され、**2四半期連続で違反すると新規融資が凍結される。**

BAL は4条項すべて充足しており、財務健全性は `healthy`。

### 7.5 緊急融資

通常の借入枠が尽きたときの最後の手段。

- 年利 15〜20%
- 担保価値の 50% まで、かつ絶対上限 $30,000,000
- 期間 2四半期
- 使うと金利サーチャージ +10% が翌期以降にかかる

支払不能が3四半期連続すると、より深刻な状態として扱われる。

## 第9部　市場価格のしくみ

### 9.1 世界のHOSO価格

原産国ごとに FOB 価格が形成される。2015年の初期値:

| 国 | 初期FOB価格 |
|---|---|
| エクアドル (EC) | $4.70/kg |
| インド (IN) | $5.25/kg |
| インドネシア (ID) | $5.45/kg |
| ベトナム (VN) | $5.60/kg |

価格は需給圧力に応じて変化する。国別の圧力 L と世界全体の圧力 G を 60:40 で合成し、その 70% が需給不均衡、30% がコスト変化に由来する。四半期あたりの変化率は **±20% に制限**される。

**Phase 6.3 で追加された自己修正機構**が重要である。それ以前は、需要配分が固定シェアだったため国別の需給不一致が恒常的に残り、価格が絶対下限 $0.50 まで発散する問題があった。3つの修正で対処している。

1. 需要が安い原産国へ移動する（価格感度 2.0）
2. コスト連動の長期アンカー価格への平均回帰（回帰率 0.8）
3. 国別価格をグローバル基準から ±35% にクランプ

**実例（2015Q2）**: 世界供給 1,804,994t に対し需要 1,206,700t、不均衡 −0.3315 という大幅な供給過剰。原産国別HOSO価格は EC $4.2189（前期比 −13.59%）、IN $3.9025、ID $3.9228、VN $4.0800。

### 9.2 PD/VAPプレミアム

HOSO 価格に上乗せされる。

```
プレミアム = HOSO価格 × ベース比率 × 稼働率倍率 + 品質加点
```

ベース比率は PD 18%、VAP 55%。稼働率（需要÷加工能力）が基準 0.85 からずれると倍率が変わる（感度0.8、範囲 0.5〜1.8）。品質スコアが 50 を超えた分だけ加点される（感度0.3）。

**実例（2015Q2）**: PD は稼働率 0.6917 でベースプレミアム 0.6337。VAP は需要 144,611 に対し能力 172,106、稼働率 0.8402 でベースプレミアム 2.1998、理由コード `QUALITY_PREMIUM_APPLIED`。

### 9.3 ベトナム国内原料価格

加工業者の買付上限価格と、農家の留保価格の綱引きで決まる。

**買付上限価格**は、輸出価格から加工輸出費用（$0.85/kg）と必要マージン（$0.25/kg）を引いた水準。

**農家の留保価格**は $2.25/kg で、内訳は 養殖コスト $1.90 + 疾病リスク引当 $0.15 + 最低マージン $0.20。この価格を下回ると農家は売らない。

買付上限が留保価格を下回ると、取引量そのものが縮小する。10%下回ると取引量が約20%減る感度。

**実例（2015Q2）**: 国内価格 $2.4760、買付上限 $2.9800、農家留保価格 $2.25。供給 451,306t に対し未販売 114,908t、不均衡 −0.2546。理由コード `VIETNAM_RAW_MATERIAL_SURPLUS`。つまり原料は余っており、買い手市場である。

外部加工業者（プレイヤー5社以外）が国内供給の 70% 前後を吸収する前提になっている（基準 450,000t × 0.7 = 315,000t/四半期）。5社の合計シェアは 15〜23% 程度。

## 第10部　勝ち方の考え方

ここまでの仕組みから導かれる、意思決定の指針をまとめる。

### 10.1 最初に確認すべき3つの数字

**① 使える原料は何トンか。** 在庫合計ではなく `available` ステータスのロットだけを数える。養殖中・輸送中は使えない。

**② 約定残は何トンか。** 前期に成約した契約は今期が納期である。これを埋められないと納期信頼性が落ち、顧客信頼が落ち、将来の成約競争力が落ちる。

**③ 必要な正社員は何人か。** 生産計画から逆算する。余った人数はそのまま損失になる。

### 10.2 営業人員の配分原則

営業人員は総数が固定されているので、**配分がすべて**である。

- 成約能力は逓減する。1市場に集中させるより分散させたほうが合計は大きい
- **0人でも200トン成約する。** 利益率の低い市場×商品は 0人にして、200トンだけ拾う
- **35%上限に注意。** 小さな市場に人を集中させると能力が余る。特に日本向けVAP（上限704.49t）は2人で足りる
- 限界利益の高い順（VAP > PD > HOSO、日本 > EU > 米国 > その他 > 中国）に、35%上限の範囲内で人を割り当てる

BAL の Turn 3 推奨案は、この原則に従って 7,127.6t → 10,060.94t（+41%）の改善を達成している。追加コストはゼロである。

### 10.3 人員配置の原則

**必要最低限 + 5% 程度の余裕。** それ以上は遊休人件費として捨てているのと同じ。

現行バージョンでは人員を削減しても品質は悪化しない（第6部6.4節）。したがって削減のデメリットは実質的に無い。

### 10.4 資金繰りの原則

国内買付は当期現金払い、売上回収は翌期。したがって**買付を増やした四半期は必ず現金が減る**。

借入余力は担保ベースで決まり、その担保の大半は売掛金（掛け目0.70）である。売上が伸びれば担保も増えるが、既存借入が大きいと枠は残らない。

BAL は現在、借入余力ゼロで現金 $31.6M。この制約下で Turn 3 を設計する必要がある。

### 10.5 設備投資の原則

**能力が増えるまで最短で4四半期、VAP なら7四半期かかる。** 目先の四半期の助けにはならない。

品質管理設備と環境設備は、現行バージョンでは純粋なコスト増である。選ばない。

投資すべきなのは、**恒常的にボトルネックになっている能力プール**である。制約要因の記録を数四半期分見て、同じ制約が繰り返し出ているかを確認してから決める。

### 10.6 よくある失敗

| 失敗 | 帰結 |
|---|---|
| 在庫合計を使える原料だと思う | 生産計画が実行できず約定残が膨らむ |
| 正社員を多めに配置しておく | 遊休人件費で黒字が消える（BALで$328万） |
| 日本向けVAPに営業を集中させる | 35%上限で頭打ち、能力が無駄になる（BALで867t分） |
| 20%を超える値下げをする | priceScore が上限に張り付き、値引き分が丸損 |
| 品質管理設備に投資する | 便益ゼロでコストだけ増える |
| 黒字だから資金は大丈夫だと思う | 営業CFが大幅マイナスになりうる（BALで−$5,645万） |

## 付録　用語集

| 用語 | 意味 |
|---|---|
| HOSO換算トン | すべての数量の統一単位。「元の有頭殻付きエビ何トン分か」。物理歩留まりは単位定義に織り込み済み |
| 公称能力 / 実効能力 | 実効 = 公称 × 0.855（基準稼働率0.90 × 設備可用率0.95） |
| 約定残 | 成約済みだが未履行の契約数量 |
| 成約競争力 | 価格・カバレッジ・関係・品質・納期の加重合成値。これに比例して需要が配分される |
| 35%上限 | 1社が1市場×商品の需要から取れる最大シェア（`maximumSupplierShare`） |
| 遊休人件費 | 配置しなかった正社員の給与。売上原価に計上される |
| 操業リスク | 品質のすべての起点となる 0〜1 の合成指標 |
| 制約要因 | 生産量を決めた5段階のうちどれが効いたかの記録 |
| 理由コード | 市場や会社の状態を説明する定型コード（例 `SALES_FORCE_SHORTAGE`） |
| available / growingAquaculture / inTransitImport | 原料ロットのステータス。生産に使えるのは `available` のみ |

# マニュアル2冊へ反映すべき変更点（INT-1候補ベース）

更新: 2026-10-07 JST / 本格的な編集は司令塔でまとめる。ここは差分の洗い出しのみ。

## 1. 管理者（GM）向けマニュアル

| 箇所 | 変更の種類 | 内容 |
| --- | --- | --- |
| Run作成 | 追記 | 「販売市場モデル」の選択項目を追記する。選択肢は「従来市場モデル」「三層顧客価格モデル V2.00候補」「三層顧客価格モデル V2.00＋市場集中価格下落」。**Run作成後は変更不可**であることを明記する。既定は従来市場モデル。 |
| Run作成 | 追記 | 管理者ログインの固定導線（Setup画面右上「🔐 管理者ログイン」）を追記する。端末・ブラウザを変えると認証セッションは別であることを書く。 |
| バランス調整 | 変更 | 配当性向の指定が **PLAYER会社にも適用される** ようになった。従来「Standard AI会社のみ」と読める記述があれば修正する。 |
| バランス調整 | 追記 | 0%の明示指定と未指定は意味が違うことを明記する（0%＝配当しないという指示。未指定＝AIの既定に任せる）。 |
| 年度末処理 | 追記 | 「年間配当」パネルの読み方を追記する。年間純利益・適用率・年間目標・年度内既払・年度末追加目標・実支払・未達額と理由・出所（管理者指定／AI）が会社別に出る。 |
| Turn進行 | 変更 | 保存が revision ベースの競合検出になった。競合時は保存が拒否され理由が出る。再読み込みしてやり直す手順を書く。 |
| Turn進行 | 追記 | 保存が認証切れ（403）で失敗した場合の「こちらから再ログイン」導線と、戻ってから「1 Turn」を押し直す手順を追記する。 |
| トラブル対応 | 新規 | 「Turn進行で『意思決定が不正です』と出た場合は、GM が Console の『この会社を操作』から代理で確定し直す」を追記する（PLAYER自身は同一Turnへ再提出できない）。営業人員の上限超過は提出時に止まるようになったため、この経路で起きる頻度は下がる。 |
| トラブル対応 | 新規 | 認証切れ（403）で保存が失敗した場合、Console は赤帯で「サーバー保存（正本）が失敗しました／このまま進めると保存されずに失われます／Turnを進めるボタンを無効化しています」と表示し、以降の進行をブロックする。再ログイン後は**保存が成立していた地点から**再開になるため、保存に失敗したTurnは再実行することを書く。 |
| 復旧 | 新規 | 進行中Runの復旧は「最後に保存が成立した地点からの再開」のみで、任意の過去Turnへは戻せないことを明記する。監査用Excelは復旧用の保存物ではない。 |
| 分析画面 | 追記 | COMMERCIAL GROWTH について、PLAYER が決めたTurnでは ①〜④ が「AI参考値」であり PLAYER の実提出量は未取得である旨、表の「決定者」列で判別できる旨を追記する。 |
| 出力物 | 追記 | 監査用Excelに市場集中価格低下（Crowding）の価格形成診断が含まれることを追記する。 |

## 2. 参加者（PLAYER）向けマニュアル

| 箇所 | 変更の種類 | 内容 |
| --- | --- | --- |
| 提出操作 | 変更 | 「確定／提出」はサーバ保存が成立してから確定表示になる。押した直後は「保存中…」でボタンが無効になる。**表示が変わるまで画面を移動しない**ことを強調する。 |
| 提出操作 | 新規 | 無効な数値があると「入力に無効な値があるため提出できません（値は保存していません）」が出る。該当項目を直して再提出する。従来のように黙って0になったり行が消えたりしないことを書く。 |
| 提出操作 | 新規 | 同じTurnへ2回提出はできない。間違えたら GM に申し出る。 |
| 提出操作 | 新規 | 入力途中でページを再読み込みすると未確定の下書きは失われる。確定済みの意思決定は残る。 |
| 配当 | 変更 | 管理者が配当性向を指定している場合、**配当欄を操作しなくても** 年度末（Q4）に自動精算される。FINANCE画面に年度中の参考表示が出る。 |
| 配当 | 追記 | 年度途中に金額指定で支払った配当は、年度末の追加支払から差し引かれる（二重払いにはならない）。 |
| 投資 | 変更 | 新工場建設カードの説明が変わった。新設する工場のフルランプ能力と、稼働開始からの立ち上がり（0四半期目50%→1四半期目75%→2四半期目以降100%）が表示される。**当期の処理見込みは増えない**（稼働は完成後）ことを書く。 |
| 営業人員 | 追記 | 1四半期あたりの採用上限（現員の30%、最低3人）を超えると、GM の進行時にエラーになることを書く。 |
| 画面の見方 | 追記 | 市場集中価格低下モデルのRunでは、同じ商品に各社の供給が集中すると価格が下がる。ヘッダの「販売市場モデル」で確認できる。 |
| 画面の見方 | 新規 | **商品別（HOSO/PD/VAP）の受注残**が SALES / PRODUCTION 画面の先頭で見られるようになった。受注残合計・納期超過・当期納期・将来納期を分けて表示する。「納期が来ていない受注残は遅延ではない」ことを明記する。 |
| 画面の見方 | 新規 | **前四半期の借入結果**が FINANCE 画面の先頭で見られるようになった。申請額と実行額は別の値であること、減額・否認の理由が記録として出ること、緊急融資の実行有無と適用金利が出ることを書く。記録が無い場合は「未取得」と出る。 |
| 入力 | 変更 | 負数や範囲外の数値を入れても、その場で0や上限に書き換わらない。打った値が残り、提出時に理由つきで止まる。「勝手に0になった」という従来の挙動の説明は削除する。 |
| 営業人員 | 変更 | 採用上限を超えた入力は**提出の時点で**止まる（従来は GM の進行時に止まり直せなかった）。その場で直して再提出できることを書く。 |
| 画面の見方 | 新規 | **最初の四半期（Turn 1）は、既存借入の支払利息が発生しない**。融資は実行した四半期には利息が付かない決まりで、初期借入もゲーム開始の四半期に実行された扱いになるため。元本の返済は Turn 1 から発生する。「残高があるのに利息が0」は不具合ではないことを明記する。FINANCE 画面（Turn 1 のみ）と、Turn 1 のふりかえりの「利息・元本返済」に同じ説明が出る。 |
| 画面の見方 | 新規 | **前四半期の損益計算書の内訳**が Overview の「業績の内訳（損益計算書）」で見られるようになった。純売上から当期純利益までの各段と、kgあたり指標（平均販売単価・原料費・固定費・営業利益）を表示する。エンジンが確定値として持っていない項目（純売上の商品別内訳）は「未実装」と出ることを書く。 |
| 画面の見方 | 変更 | 減産の原因（原料不足・設備能力不足・労働力不足）は、制約の適用順（原料 → 共通前処理 → 凍結・包装 → 商品別 → 人員）で**段階ごとに分けて**集計するようになった。3つの合計は減産量と一致する。どの商品のラインで制約が掛かったかも併記される。従来は同じ減産量が複数の原因へ重複計上されていた。 |
| 画面の見方 | 変更 | PRODUCTION 画面の凍結・包装の列は「現在の処理計画」から「**現在の処理見込み（制約適用後）**」に変わった。PROCUREMENT 画面の「Planned Production 計画生産量」は制約適用**前**の計画値で、別の指標であることを書く。 |
| 画面の見方 | 新規 | **SALES 画面の先頭に「今期この商品を何トンまで売る計画にできるか（目安）」が出るようになった**。完成品在庫・当期の実効加工能力・その合計（納められる上限）・受注残・新規販売に回せる量・今の販売計画を商品別に並べる。上限を超えた入力と、上限内でも受注残で足りない入力を別の警告で示す。**AIの初期提案は在庫・受注残・実効能力を見ていない**ため、この表で必ず確かめることを書く。 |
| 営業人員 | 新規 | **減員の費用が入力する前から表示される**。営業人員1人あたりの四半期給与（$8,000）と退職金の単価（四半期給与2四半期分＝1人 $16,000、減員を決めた四半期に一括）を常に出す。減員を決めた四半期は対象者の給与も満額かかる（その四半期の負担は1人 $24,000）こと、人数が減るのは次の四半期からであることを書く。 |
| 画面の見方 | 変更 | **最初の四半期は国内原料の「前期価格」が存在しない**。従来は画面ごとに $0.00 / 0.000 / 「未確定」とバラバラに出ていたが、すべて「未確定（最初の四半期は前期がない）」と書き、代わりに「開始時の国内原料参考価格」を併記するように統一した。Turn 1 はこの参考価格以上を提示すれば通常条件で買えることを書く。 |
| 用語 | 変更 | **「原料在庫」は2つの意味がある**。INFO タブの「原料在庫 合計」は使用可能＋輸送中・養殖中の合計で、内訳（うち今期使用可能／うち輸送中・養殖中）を併記する。ふりかえりの「期末の原料在庫」と Inventory タブの「原料在庫」は**使用可能分のみ**であることをラベルに明記した。両者の数字が違うのは不具合でない。 |
| 画面の見方 | 変更 | **前期 PL の「原料費の参考欄」は買付額ではない**。「当期に投入した原料の原価（調達元別）」へ見出しを変え、国内の行は「うち 国内原料（期首在庫からの投入を含む）」とした。当期の買付量×単価と一致しないのは期首在庫からの投入を含むためであり、計算違いではないことを書く。 |
| 画面の見方 | 新規 | **VAP商品開発費が前期 PL の販管費内訳に明示行として出る**（従来は「その他（内訳に現れない差分）」へ落ちていた）。また INVESTMENT 画面で、その Run で VAP 商品開発スコアが**どの経路で成約に効くか**を表示する。三層顧客価格モデルの Run では VAP の「差別化」評価として効き（プレミアム層ほど強い）、従来市場モデルの Run ではウェイトの割合で効く。HOSO・PD の成約には効かない。 |
| 画面の見方 | 変更 | **市場集中による価格下落の説明は Run の設定に従う**。従来は「混雑度のデータがまだ無い」ことから「この Run では価格下落が働かない」と書いていたが、Turn 1 はそもそも前四半期の市場結果が無いだけである。市場集中価格下落モデルの Run では「働くが次の Turn から表示される」と出る。 |
| 画面の見方 | 変更 | **Market タブの出所バッジが「需要」と「基準価格」の2つに分かれた**。需要量は遅行する業界統計（原則 2 四半期前）なので Turn 2 でも「開始時の市場情報」のままである一方、基準価格は前 Turn の市場実績に切り替わる。見出しが「開始時の市場情報」のままに見えても価格が古いわけではない。 |
| 画面の見方 | 新規 | **Inventory タブは Turn 1 でも期首在庫を表示する**（完成品在庫・原料在庫の使用可能分・輸送中・養殖中分・受注残）。従来は「まだ確定した実績がありません」だけで、手元の期首原料が読めなかった。 |
| 提出操作 | 変更 | **提出直後の表示が「提出済み・GMの進行待ち」になった**（従来は「この四半期はすでに進行済みです」と出て、まだ Turn が進んでいないのに進んだと誤解された）。 |
| 画面の見方 | 新規 | **借入余力が $0 になる理由が表示される**。担保による上限・稼ぐ力による上限・信用区分による自己資本倍率の上限・総枠・すでに借りている残高を並べる。**信用区分が A でも、総枠を既存残高が使い切っていれば余力は $0 になる**（信用区分は「自己資本倍率の上限」にしか関与しない）ことを書く。 |
| 配当 | 新規 | **配当可能額が $0 のとき、理由と分配可能利益の額が表示される**。配当可能額は「現金」と「分配可能利益」の小さい方であり、Turn 1 は利益が1四半期も確定していないため $0 になる（現金があっても配当できない）。 |
| 用語 | 変更 | PROCUREMENT 画面の「Funding Gap」を「**資金不足額（国内買付）**」に改め、足りているときはマイナスの数字でなく「不足なし（余裕 $○○）」と出すようにした。 |
| 画面の見方 | 新規 | **養殖の「池入れ量 → 期待生産量」の換算式が画面に出る**（池入れ量 ×（1 ＋ 0.50 × 養殖強度））。養殖強度を上げると歩留まりが最大 50% まで増える一方、疾病に弱くなり収穫時の生残率が下がる（期待生産量にはその影響がまだ入っていない）ことを書く。 |
| 画面の見方 | 削除 | プレイヤーに見えていた開発者向けの文言（ソースのファイルパス・変数名・「研修では投資しないでください」等）を削除した。マニュアルへこれらの記述を載せない。 |

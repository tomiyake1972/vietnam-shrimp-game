# ShrimpX V2.00 研修試行 — 研修前チェックリスト

更新: 2026-10-07 JST / 対象: ローカル統合候補（配備前）

## A. 配備前（技術側）

- [ ] この統合候補が commit され、専用branchへ push されている（現時点では未commit）。
- [ ] Staging 環境の `STAGING_KV_REST_API_URL` / `STAGING_KV_REST_API_TOKEN` が設定済みで、production とは別の Redis を指している。
- [ ] `STAGING_ADMIN_TOKEN` が設定され、研修当日の運営者に共有されている。
- [ ] Staging の Redis に、研修で使う Run 以外の古いRunが混在していないか確認した（既存Runは書き換えない）。
- [ ] 保存形式 v9 で保存されることを確認した（配備後に v8 までのコードへ戻すと、v9で保存したRunは読めない）。
- [ ] 復旧方針を共有した: 進行中Runの復旧は「最後に保存が成立した地点からの再開」だけであり、任意の過去Turnへは戻せない（`docs/int1/staging_deployment_plan.md` §5）。
- [ ] 実配備環境での `npm run build` と動作確認を、配備時の必須ゲートとして実施する予定になっている（隔離環境での build 全工程成功は実Stagingの検証ではない）。
- [ ] `ANTHROPIC_API_KEY` の有無を確認した。無い場合、AI経営説明は失敗表示になる（ゲーム進行には影響しない）。

## B. 研修開始前（運営側）

- [ ] 管理者ログインが当日の端末・ブラウザで通ることを確認した（PC / iPad / 別ブラウザは別セッション）。
- [ ] Scenario・Seed・各社の経営モード（PLAYER / STANDARD_AI）を決めた。
- [ ] 販売市場モデルを決めた。市場集中価格低下を使うなら「三層顧客価格モデル V2.00＋市場集中価格下落」を選ぶ。**Run作成後は変更できない。**
- [ ] 管理者指定の配当性向を使うか決めた。使う場合は Turn1 の前に `continuing` で設定した。
- [ ] 0% を指定するのか、未指定にするのかを意識して決めた（両者は別の意味）。
- [ ] 参加者分の参加リンクを発行し、各参加者へ渡した。**再発行すると旧リンクは無効。**
- [ ] 参加者の端末でリンクが開き、会社名が正しく表示されることを1人ずつ確認した。
- [ ] テストで1Turn進めて、提出 → Advance → 次Turn表示までが通ることを確認した（本番Runとは別のRunで）。

## C. 研修中の運用ルール（参加者へ事前に伝える）

- [ ] **入力途中でページを再読み込みしない。** 未確定の下書きは失われる（失われた場面では画面に再入力の案内が出る）。確定済みの意思決定は残る。
- [ ] 「確定」「提出」を押したら、表示が「意思決定済み」「GMの進行待ち」に変わるまで待つ。すぐ画面を移動しない。
- [ ] 赤字のエラーが出たら、書かれている項目を直して再度確定する（値は保存されていないので同じTurnのまま直せる）。
- [ ] 同じTurnへ2回提出はできない。間違えたら GM に申し出る。
- [ ] 営業人員の採用は1四半期あたり上限がある（現員の30%、最低3人）。上限を超えると**提出の時点で**止まるので、その場で直せる。
- [ ] 商品別の受注残は SALES / PRODUCTION 画面の先頭で見られる。前四半期に実際に借りられた額は FINANCE 画面の先頭で見られる。

## D. 研修中に起きたら（運営の対処）

| 症状 | 対処 |
| --- | --- |
| 「1 Turn」が押せない | 参加者パネルで未提出の会社を確認する。該当者に提出を促す。 |
| 保存が403で失敗する | エラー内の「こちらから再ログイン」→ 戻ってから「1 Turn」を押し直す。 |
| 確定が「競合しました」と出る | その画面を再読み込みしてから、もう一度確定する。 |
| Turn進行で「意思決定が不正です」と出る | 営業人員の上限超過は提出時に止まるようになったため通常は起きない。それ以外の理由で出た場合は、その会社を Console の「この会社を操作」で開き、GM が代理で確定し直す。 |
| PLAYER画面のTurn表示が古い | 「経営管制室へ戻る」→「この会社を操作」で開き直す。Independent Player は自動更新される。 |
| 参加者がリンクを失った | 参加リンクを再発行して渡す（旧リンクは無効になる）。 |
